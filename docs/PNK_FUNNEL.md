# Воронка ПНК (потенциальный новый клиент)

**Статус:** MVP в коде (2026-07).  
**Принцип:** та же карточка клиента; отличается жизненный цикл и абонемент БЗ (неплатный). Оформление = платный абонемент → ДК.

## Этапы сделки (фиксированные)

| Код | Смысл |
|-----|--------|
| `new` | Создан |
| `assigned` | Передан тренеру |
| `contact` | Касание (звонок / Max) |
| `agreed` | Дата пробной согласована |
| `trial_done` | Пробная проведена |
| `won` | Оформление (ДК) |
| `lost` | Отказ |

## Чеклист качества (не отдельные колонки)

`contact` · `trial` · `nutrition` · `homework` — даты в `pnk_deliverables`.  
Позже: `tpi`, `assessment`, `efficiency` — те же ключи.

## Роли

| Роль | Действие |
|------|----------|
| Менеджер / админ | Создаёт ПНК, назначает тренера, видит ленту и % |
| Тренер | Звонок/Max, дата+комментарий, пробная, питание/ДЗ, оформление/отказ |
| Управляющий | позже — тот же контроль |

## Данные

Колонки на `clients` + `membership_types.is_pnk_trial`.  
Логика: `src/lib/pnk/*`. API: `admin-data?action=pnk`.  
В справочнике типов отметьте **БЗ** флагом `is_pnk_trial`.

## Миграция

```bash
npm run db:migrate:pnk -- --linked
```

## Сценарий (менеджер + тренер)

**Клиент:** «Сценарий ПНК Иванов», телефон `+79001234567`.

### Менеджер
1. `/sales` → **ПНК** → чип **Создать ПНК по сценарию** (или **+** и **Пример сценария**).
2. Выбрать тренера → **Передать тренеру**.
3. После создания — две кнопки как у ДЗ/питания: **В Max** (копирует текст и открывает Max) или **Другой мессенджер** (копирует и системное «Поделиться»).
4. На карточке в работе те же кнопки (текст под этап: звонок, дата, неявка, пакет…).
5. Контроль: фильтры **Все / Внимание / Ждут звонка / С датой / После пробной**.

### Тренер
1. Клиенты → фильтр **ПНК** → открыть карточку.
2. Чип **Дальше: …** подсказывает шаг.
3. **Позвонил / Max** → дата → **Сохранить дату** → пробная → чипы **Питание** и **ДЗ**.
4. **Оформлен (ДК)** или **Отказ**. Если не пришёл — **Перенести дату** / закрыть.

### Статистика
ПНК за период · оформления · % · по тренеру; качество: % с питанием / ДЗ.
