# Мои Звонки — клубные SMS и звонки

**Статус:** ✅ **в проде** (2026-08-14): SMS + исходящий звонок (`calls.make_call`) + журнал связи + исход через webhook `call.finish`.  
**Входящие (MVP):** код + миграция `direction` (2026-08-16). Webhook создаёт «Вход.» **только** если Мои Звонки явно передали входящее направление (`direction`/`incoming`); иначе не угадываем. Один клуб на login МЗ. После деплоя API.
**Per-club:** ✅ свой аккаунт на клуб (`club_iskra_settings.moizvonki`); общий `MOIZVONKI_*` — запасной.  
**Не путать с:** Max у тренера (личный чат) и с номерным Max-шлюзом.
**Прод:** https://fitness-diary-bice.vercel.app · миграции `club_call_log` + `outcome` (см. ниже).

## Зачем

Менеджер / админ из списка клиентов:
- **SMS** — с Android-телефона клуба через API Мои Звонки;
- **Звонок** — исходящий вызов с того же Android (`calls.make_call`);
- **Max** — копирует текст «от клуба» и открывает чат клиента (без Мои Звонки).

Текст SMS — **от имени клуба** («Это {club_name}»), не «это твой тренер».
Звонок — клиент видит **номер телефона клуба** (того, на котором приложение Мои Звонки).

## Что настроить у себя

1. Аккаунт на [moizvonki.ru](https://www.moizvonki.ru/), Android с приложением Мои Звонки онлайн.
2. В приложении на телефоне: **режим отправки SMS без подтверждения** (иначе каждое SMS ждёт тап на телефоне).
3. В кабинете: **Настройки → Интеграция → Параметры API** — адрес (`https://ВАШ_ДОМЕН.moizvonki.ru/api/v1`) и ключ.
4. **Если ключ попал в чат / скрин — сразу смените** ключ в кабинете и в Оси / env.

### Предпочтительно: на клуб в Оси

**Структура → Max и SMS → блок «Мои Звонки»** (нужен выбранный клуб): email, домен/URL, API-ключ.  
Пишется в `club_iskra_settings.moizvonki` (только сервер; в UI ключ не показывается).  
Миграция: `supabase/migrations/20260805230000_club_iskra_moizvonki.sql`.

### Запасной вариант: общий env (Vercel)

Только serverless, **без** `VITE_*` — один телефон на всю сеть, если у клуба нет своего блока:

| Переменная | Пример |
|------------|--------|
| `MOIZVONKI_DOMAIN` | `fitcity` → base `https://fitcity.moizvonki.ru/api/v1` |
| или `MOIZVONKI_API_BASE` | полный URL `/api/v1` |
| `MOIZVONKI_API_KEY` | ключ из кабинета |
| `MOIZVONKI_USER_EMAIL` | email пользователя Мои Звонки, **с чьего телефона** уйдёт SMS |

После смены env — **Redeploy**. Локально: те же переменные в `.env` (см. `.env.example`).

Приоритет: **полный конфиг клуба** → иначе поля клуба + env → иначе только env.

## Как пользоваться в Оси

1. Админка / продажи → **Клиенты** (нужен выбранный клуб).
2. Иконки **Max**, **SMS** и **Позвонить** у строки:
   - **Max** — копирует текст и открывает чат (ссылка Max или share);
   - **SMS** — лист «SMS от клуба» (сообщение **не** уходит сразу);
   - **Позвонить** — подтверждение → набор на Android; после запуска — лист **пометки** (чипы + текст), без инфо-простыни.
3. **Фильтры воронки** (ДР / Истекает / Закончился / Давно не был) — в листе SMS сразу шаблон клуба; можно править → **Отправить** / **Отмена**.
4. **Все / не активные / ждёт старт / поиск** — пустое поле SMS: напишите свой текст → **Отправить**. Без текста кнопка неактивна.
5. После отправки SMS:
   - запись в **облачный** журнал `club_sms_log` — и **успех (`ok`)**, и **ошибка (`fail` + причина)**;
   - у кнопки SMS — отметка только по успешным (`ok`), TTL корзины;
   - локальный кэш на устройстве — запасной, если сеть упала при чтении.
   Сроки отметки:
   - **Истекает** — до **5** дней;
   - **Закончился** (0–13 дн.) — до **14** дней;
   - **Давно не был** (фильтр 14–60 дн.) — отметка до **14** дней;
   - в **Все / неактивные** — видна, если горит отметка *текущей* корзины, либо SMS **сегодня**.
6. После звонка: запись в **`club_call_log`** (ok / fail команды API). Короткий тост «Набор на телефоне клуба» — не длительность разговора. Пометку пишут сразу в листе или позже в журнале. Исход и **запись** — в журнале (плеер).
7. **Журнал звонков (общий):** отдельный раздел — плитка «Журнал звонков» (`/admin|sales|club/call-log`): экран на всю высоту; вкладки **Список** (таблица), **Сводка**, **SMS**. Не в Структуре.
8. **История связи** — в списке «Клиенты» → ⋮ → «История связи» (окно сверху); вкладки **Звонки** / **SMS**; период **день** или **Всё время** (до 90 дн.). В карточке — иконка у ФИО. Админ / менеджер / управляющий; тренеру нет.
9. **Главная менеджера «Кому звонить»** — третий слот рядом с планом и ПНК. В очередь: пометки-перезвон и пропущенные/короткие. **Не** в очередь: после успешного ответа без «перезвонить», свежий pending (~2 ч), пометка «отказ / не звонить», архив.
10. Журнал SMS: Структура → **Max и SMS** → «Журнал SMS клуба»; с доски Клиенты — кнопка «Журнал SMS» в итоге массовой.
11. Шаблоны SMS — только `club_sms_templates`, **не** шаблоны Max тренера.

Миграция статусов журнала SMS: `supabase/migrations/20260813210000_club_sms_log_status.sql`  
Миграция журнала звонков: `supabase/migrations/20260813220000_club_call_log.sql`  
(`npm run db:migrate:club-call-log -- --linked`).  
Миграция статусов журнала SMS: `npm run db:migrate:club-sms-log-status -- --linked`.

Если ни клуб, ни env не настроены — кнопки SMS и «Позвонить» неактивны.

## Массовые SMS (доска клиентов)

Доступно **админу, менеджеру и управляющему** на экране Клиенты (`/admin/clients`, `/sales/clients`, `/club/clients`).

1. Выберите фильтр/вкладку как обычно.  
2. **Массовые SMS** → галочки (сразу все с телефоном; лишних снимите).  
3. **Текст и отправка** → один общий текст (на сценарии подставится черновик шаблона клуба).  
4. Окно: текст, кому, сколько SMS, примерное время → **код подтверждения** (тот же, что при удалении клиента) → очередь.  
5. Отправка по одному через существующий `POST club-sms`, с паузой под лимит **20 SMS/мин** на клуб; при 429 — ждёт и повторяет. Можно **Остановить**.  
6. После пачки — окно итога: сколько ушло / ошибок + список причин; оттуда же — журнал SMS клуба.

Код: `clubSmsCampaignCore.js`, `clubSmsCampaignRunner.js`, `clubSmsCampaignResultCore.js`, `useAdminClubSmsCampaign.js`.  
Проверка: `node scripts/verify-club-sms-campaign.mjs`, `node scripts/verify-club-sms-campaign-result.mjs`.

## API

- `GET /api/admin-data?action=club-sms&club_id=` → `{ configured, moizvonki, templates, club_name }`
- `GET …&logs=1&since_days=14` → то же + `logs[]` журнала SMS; `&day=YYYY-MM-DD` — один день по календарю клуба (МСК)
- `POST /api/admin-data?action=club-sms` body: `{ club_id, client_id, text? , scenario? }`  
  Роли: admin / sales_manager / supervisor своего клуба. Массовая кампания = N таких POST с клиента.
- `GET /api/admin-data?action=club-call&club_id=` → `{ configured, moizvonki, club_name }`; `&logs=1` — журнал; `&day=YYYY-MM-DD` — один день МСК; `&glance=1` — очередь «кому звонить» (`staff_note` + missed/short); опционально `&client_id=`
- `POST /api/admin-data?action=club-call` body: `{ club_id, client_id }` — `calls.make_call`; лимит ~10/мин; в журнал ok/fail (не 429); `outcome=pending` до webhook
- `POST /api/admin-data?action=club-call` body: `{ op: 'note', club_id, log_id, staff_note }` — пометка к строке (пусто = сброс)
- `POST /api/admin-data?action=moizvonki-webhook&secret=` — входящий webhook Мои Звонки (без Bearer); `call.finish` → исход исходящего **или** новая строка входящего (`direction=inbound`, клиент по телефону или без карточки); секрет `MOIZVONKI_WEBHOOK_SECRET`
- Настройки аккаунта: `GET/POST` `action=iskra-settings` — поле `moizvonki` (admin; ключ в ответе не отдаём).

Подписка webhook (один раз): задать секрет в Vercel + `node scripts/subscribe-moizvonki-call-webhook.mjs` (нужны `MOIZVONKI_*`).  
Миграция исхода: `npm run db:migrate:club-call-outcome -- --linked`.  
Миграция записи: `npm run db:migrate:club-call-recording -- --linked`.
Миграция пометки: `npm run db:migrate:club-call-staff-note -- --linked`.  
Миграция входящих: `npm run db:migrate:club-call-inbound -- --linked`.

Код: `api/_lib/moiZvonkiCore.js`, `moiZvonkiHandler.js`, `moiZvonkiCallHandler.js`, `moiZvonkiWebhookHandler.js`, `src/lib/admin/moiZvonkiClubConfigCore.js`, `clubSmsLogCore.js`, `clubCallLogCore.js`, `clubCallOutcomeCore.js`.  
Проверка: `node scripts/verify-moi-zvonki.mjs`, `node scripts/verify-moi-zvonki-call.mjs`, `node scripts/verify-club-call-log.mjs`, `node scripts/verify-club-call-outcome.mjs`, `node scripts/verify-club-outreach-stats.mjs`, `node scripts/verify-moi-zvonki-club-config.mjs`.

| # | Сценарий | Что увидите | Почему |
|---|----------|-------------|--------|
