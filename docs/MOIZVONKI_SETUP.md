# Мои Звонки — клубные SMS

**Статус:** ✅ в проде (админка → Клиенты → SMS; облачный журнал + шаблоны отдельно от Max).  
**Не путать с:** Max у тренера (личный чат) и с номерным Max-шлюзом.

## Зачем

Менеджер / админ из списка клиентов отправляет SMS **с Android-телефона клуба** через API Мои Звонки. Ссылки на чат Max не нужны. Текст — **от имени клуба** («Это {club_name}»), не «это твой тренер».

## Что настроить у себя

1. Аккаунт на [moizvonki.ru](https://www.moizvonki.ru/), Android с приложением Мои Звонки онлайн.
2. В приложении на телефоне: **режим отправки SMS без подтверждения** (иначе каждое SMS ждёт тап на телефоне).
3. В кабинете: **Настройки → Интеграция → Параметры API** — адрес (`https://ВАШ_ДОМЕН.moizvonki.ru/api/v1`) и ключ.
4. **Если ключ попал в чат / скрин — сразу нажмите «Изменить»** и обновите env. Старый ключ перестанет работать.

## Env на сервере (Vercel)

Только serverless, **без** `VITE_`:

| Переменная | Пример |
|------------|--------|
| `MOIZVONKI_DOMAIN` | `fitcity` → base `https://fitcity.moizvonki.ru/api/v1` |
| или `MOIZVONKI_API_BASE` | полный URL `/api/v1` |
| `MOIZVONKI_API_KEY` | ключ из кабинета |
| `MOIZVONKI_USER_EMAIL` | email пользователя Мои Звонки, **с чьего телефона** уйдёт SMS |

После смены env — **Redeploy**.

Локально: те же переменные в `.env` (см. `.env.example`).

## Шаблоны (два канала)

| Канал | Где править | Тон |
|-------|-------------|-----|
| **Max тренера** | Структура → **Max и SMS** → блок «Сообщения тренеров в Max» | «Это твой тренер {trainer_name}» |
| **SMS клуба** | тот же экран → блок «SMS от клуба (Мои Звонки)» | «Это {club_name}» |

В БД: `club_iskra_settings.outreach_templates` (Max) и `club_sms_templates` (SMS). Миграция: `supabase/migrations/20260722230000_club_sms_templates.sql`.

## Как пользоваться в Оси

1. Админка → **Клиенты** (нужен выбранный клуб).
2. Иконка **SMS** у строки → лист «SMS от клуба» (сообщение **не** уходит сразу).
3. **Фильтры воронки** (ДР / Истекает / Закончился / Давно не был) — в листе сразу шаблон клуба; можно править → **Отправить** / **Отмена**.
4. **Все / не активные / ждёт старт / поиск** — пустое поле: напишите свой текст → **Отправить**. Без текста кнопка неактивна.
5. После успешной отправки:
   - запись в **облачный** журнал `club_sms_log` (видят админ и менеджеры клуба);
   - у кнопки SMS — отметка по TTL корзины (см. ниже);
   - локальный кэш на устройстве — запасной, если сеть упала при чтении.
   Сроки отметки:
   - **Истекает** — до **3** дней;
   - **Закончился** (0–13 дн.) — до **14** дней;
   - **Давно не был** (фильтр 14–60 дн.) — отметка до **14** дней;
   - в **Все / неактивные** — видна, если горит отметка *текущей* корзины, либо SMS **сегодня**.
6. Журнал смотреть: Структура → **Max и SMS** → блок «Журнал SMS клуба» (сегодня / 14 дней).
7. Шаблоны SMS — только `club_sms_templates`, **не** шаблоны Max.

Если env не задан, кнопка неактивна, подсказка про настройку.

## API

- `GET /api/admin-data?action=club-sms&club_id=` → `{ configured, templates, club_name }`
- `GET …&logs=1&since_days=14` → то же + `logs[]` (облачный журнал: клиент, сценарий, кто отправил, превью, время)
- `POST /api/admin-data?action=club-sms` body: `{ club_id, client_id, text? , scenario? }`  
  - С `text` — уходит этот текст; в журнал сценарий пересчитывается по корзине клиента.  
  - Без `text` — нужен валидный `scenario`; клиент должен подходить под фильтр сценария, иначе `400 scenario_mismatch`. Текст собирается из **club_sms_templates**.  
  - После успешной отправки — `insert` в `club_sms_log` (`log_id` в ответе; сбой журнала → `log_warning`, SMS не откатывается).  
  - **Не** подставляется `expiring` по умолчанию.  
  Роли: admin или sales_manager своего клуба.
- Шаблоны: `GET/POST` `action=iskra-settings` — поля `club_sms_templates` / `club_sms_templates_custom`.

Код: `api/_lib/moiZvonkiCore.js`, `moiZvonkiHandler.js`, `src/lib/admin/clubSmsLogCore.js`, `clubSmsSentMarkCore.js`.  
Миграция: `supabase/migrations/20260723010000_club_sms_log.sql`.  
Проверка: `node scripts/verify-moi-zvonki.mjs`, `node scripts/verify-club-sms-mode.mjs`, `node scripts/verify-club-sms-templates.mjs`, `node scripts/verify-club-sms-log.mjs`, `node scripts/verify-club-sms-sent-mark.mjs`.

## Не в MVP

Массовая рассылка, звонок (`calls.make_call`), webhook Мои Звонки как второй источник, кнопка SMS у тренера, Max по номеру, роль «старший менеджер» (читает ту же таблицу позже).
