# План операций клуба

**Версия:** 2026-07  
**Статус:** активный план — только **Планёрка** (задания в FIT-CITY).

**Не путать с:** [ISKRA_NORTH_STAR.md](./ISKRA_NORTH_STAR.md) — аналитика и советы ИСКРЫ.  
**Задания команде:** [ISKRA_PLANERKA.md](./ISKRA_PLANERKA.md).

**⏸ Отложено:** внешний контур «Релей» — [RELAY_OPERATIONS.md](./RELAY_OPERATIONS.md) (не в roadmap).

---

## Два продукта в одном приложении

| | **ИСКРА** | **Планёрка** |
|---|-----------|--------------|
| **Зачем** | Понять месяц, риски, совет | Довести **задачу** до сотрудника |
| **Кто пользуется** | Админ, руководитель | + тренер, менеджер (получают) |
| **Пример** | «План 35%, 6 неактивных» | «Иванову: обзвонить 5 неактивных до пятницы» |

```
ИСКРА (цифры и совет)  →  Планёрка (задание в приложении)
```

## Эпик O1 — ручные задания (тикеты)

**Цель:** админ ставит задачу **без ИСКРЫ** — экран «Задания клуба».

### Блок A — данные

| ID | Задача | DoD |
|----|--------|-----|
| O1-A1 | `source_channel`, `context_json` | миграция |
| O1-A2 | `source: admin`, `source_channel: manual_app` | core |
| O1-A3 | `buildManualTaskDraft()` | `staffTaskCreateCore.js` |
| O1-A4 | GET `view=sent` | ✅ есть |
| O1-A6 | `verify-operations-tasks.mjs` | agent-qa |

### Блок B — UI

| ID | Задача | DoD |
|----|--------|-----|
| O1-B1 | `/admin/club-tasks?club=` | страница |
| O1-B2 | «Новое задание» в меню | кнопка |
| O1-B3 | Форма: кому, тип, заголовок, срок | модалка |
| O1-B4 | Список «Отправленные» | статусы |

### Поля формы

Кому · Тип · Заголовок · Описание · Срок · Приоритет

POST `iskra-dispatch` с `source_channel: manual_app`.

### Блок D — управляющий (после роли supervisor)

`/trainer/club/tasks` — те же форма и список в своём клубе.
