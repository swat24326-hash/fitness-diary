# Короткая договорённость с клубом-другом (черновик)

**Зачем:** когда даёте Ядро **бесплатно** другу/партнёру.  
**Это не юрдокумент и не консультация** — текст в мессенджер «на понятном»; при платном чужом клубе — юрист и нормальный договор.

Связано: более полный черновик договора — [FRIEND_CLUB_AGREEMENT.md](./FRIEND_CLUB_AGREEMENT.md); ориентир ПДн — [STRATEGY §5.4.0b](./STRATEGY_SCALE_AND_RU_HOSTING.md).

Скопируйте блок ниже, подставьте имена при необходимости.

---

## Текст в мессенджер

Привет. Даю пользоваться программой Ядро для вашего клуба бесплатно, на своих условиях.

1. Программа и сервер — мои (ИП). Данные ваших клиентов в системе — ваши: вы решаете, кого заводить и зачем.
2. Я храню данные, чтобы приложение работало (сейчас цель — серверы в РФ). Базу не продаю и не использую «на сторону».
3. Доступы только вашим людям (тренеры/админ клуба). Общий логин на всех и доступ в мой кабинет облака — нельзя.
4. Пароли не кидать в общие чаты. Если кто-то уволился — сразу отключить.
5. Если перестаёте пользоваться — напишите: сделаем выгрузку/удаление ваших данных по договорённости.
6. Жалобы клиентов по «зачем вы нас храните» закрываете вы как клуб; по сбою программы — пишете мне.

Ок по пунктам — отвечаете «согласен» в этот чат, и заводим клуб.

---

## Как пользоваться

1. Отправить текст до выдачи логинов.  
2. Дождаться «согласен» (скрин/переписка себе в сейф).  
3. Завести **отдельный** клуб в системе, не мешать с вашим.  
4. Когда станет платно / «по-взрослому» — заменить на нормальный договор (см. [STRATEGY §5.4.0b](./STRATEGY_SCALE_AND_RU_HOSTING.md)).
