# Авто-ДЗ клиенту (по воскресеньям)

**Актуально:** 2026-10-14. Статус: шаги 0–2 (библиотека, генератор, отправка по воскресеньям) — ✅ в проде с 14.10 (`c9697520`, миграции применены). Первое воскресенье отправки — 18.10. Шаг 3 — ⏸.

## Ситуация

Тренер ведёт 20–30 клиентов. Собрать каждому ДЗ руками раз в неделю он не успевает, поэтому задание получают единицы. Цель: каждый клиент с включённым авто-ДЗ в воскресенье получает в приложении (`/me`, вкладка «От тренера») задание на неделю под свою цель, а тренер только просматривает его.

## Решения владельца (13.10.2026)

| Вопрос | Решение |
|---|---|
| Откуда разнообразие | **Генератор**: библиотека размеченных упражнений + формулы по целям. Не сотни готовых комплексов |
| Кто решает, что уходит | Автоматически, но тренер **заранее видит** и может поправить или пропустить |
| ДЗ на неделю | **2–3 разных занятия** (А / Б / В) |
| Как меняются упражнения | **Блок на 3–4 недели**: те же упражнения с ростом нагрузки (повторы, круги, секунды), потом новый набор. Новые упражнения каждую неделю — нет: клиент не успевает освоить технику и не видит прогресса |
| Цели | Похудение, набор / тонус, ОФП, статика / осанка / спина, выносливость, мобильность / растяжка |
| Пол | Не отдельные комплексы, а смещение акцентов (`focus`); тренер может поменять |
| Инвентарь | Резинка — **стандарт** (клуб выдаёт / продаёт). Гантели — с подсказкой клиенту: подручный предмет **или** упражнение-замена |
| Питание | Тот же воскресный механизм: пересчёт КБЖУ при смене веса на 3 кг — [NUTRITION_AUTO.md](./NUTRITION_AUTO.md) ✅ |

## Строение одного занятия

Каждое занятие — **разминка → основная часть → заминка**:

| Часть | Что | Откуда упражнения |
|---|---|---|
| Разминка (~5 мин) | Лёгкое кардио без прыжков, подвижность суставов, активация лопаток | `phase: 'warmup'` |
| Основная часть | По формуле цели: силовые блоки, круговая, интервалы, удержания | `phase: 'main'` + отбор по цели клиента |
| Заминка (~5 мин) | Растяжка, дыхание | `phase: 'cooldown'` |

Подвижность и растяжка попадают в основную часть только при целях «мобильность» и «осанка» — отбор по `goals`. Прыжки в разминку не попадают никогда.

## Этапы

| Шаг | Что | Статус |
|---|---|---|
| 0 | Библиотека домашних упражнений с метками + verify | ✅ |
| 1 | Генератор недели (строение занятия, формулы целей, блоки 3–4 недели, прогрессия) + вкладка «Авто» у тренера → обычный черновик ДЗ | ✅ |
| 2 | Настройки авто-ДЗ у клиента (цель, уровень, ограничения, занятия) + предпросмотр тренеру + воскресная отправка cron через `client_plans` | ✅ |

## Генератор недели (шаг 1)

**Тренер:** карточка клиента → ДЗ → вкладка **«Авто»**. Цель подставляется из цели в карте здоровья (стандартные кнопки — [HEALTH_SCREENING.md](./HEALTH_SCREENING.md)), а если она не выбрана — из опросника питания (снижение веса → похудение, набор массы → набор / тонус, поддержание → ОФП, выносливость → выносливость), пол — из карточки здоровья. Тренер выбирает уровень, ограничения («нельзя при»), 2 или 3 занятия и неделю нагрузки (1–4) → «Подобрать один раз» (видно, только пока отправка по воскресеньям выключена) → обычный черновик: правит нормы, отправляет «В Max» или «В приложение». Кнопка с перемешиванием — другой набор упражнений (новый блок).

**Как собирается:** на каждое занятие — разминка (1 лёгкое кардио + 2 на суставы), основная часть по формуле цели, заминка (3 на растяжку или дыхание). Формулы — `src/lib/homework/auto/homeworkGoalFormulas.js`: похудение и выносливость — круговая на время (3–4 круга), остальные — подходы. Нагрузка: недели 1–3 растут повторы или секунды, 4-я — плюс подход или круг. Набор упражнений зависит только от клиента и номера блока, от недели — только нагрузка. В основной части недели упражнения не повторяются, пока есть выбор. Пол: женщине в силовых целях (тонус, ОФП) добавляется упражнение на низ, мужчине — на верх. Прыжки — только с уровня 2 и никогда в разминке.

**Клиент:** под каждым упражнением раскрывается «Как делать» — описание и главное в технике; у гантелей — чем заменить. Поля `how` / `tip` в снимке `client_plans` (белый список `clientPlanCore.js`); у ручного ДЗ их нет — показ как раньше.

Код — `src/lib/homework/auto/` (`homeworkWeekGenerator.js`, `homeworkGoalFormulas.js`, `homeworkAutoDefaults.js`), экран — `src/pages/trainer/HomeworkAutoSection.jsx`. Проверка — `scripts/verify-homework-generator.mjs`.

## Отправка по воскресеньям (шаг 2)

**Тренер:** во вкладке «Авто» сверху — строка-переключатель **«Каждое воскресенье в 10:00»** (нажимается целиком). Включил — выбранные цель, уровень, ограничения и число занятий сохраняются у клиента; дальше любая их смена сохраняется сразу. Под переключателем — что уйдёт: «Вс 18.10 · неделя 2 из 4» с полоской из 4 недель и «Новый набор упражнений — с 15.11», или почему не уйдёт. Кнопки: **«Посмотреть неделю»** — неделя ближайшего воскресенья в редакторе (ровно то, что получит клиент), **«Пропустить 18.10»** — одно воскресенье без задания, кнопка с перемешиванием — другой набор: новый блок с ближайшего воскресенья.

**Поправил сам:** открыл «Посмотреть неделю», изменил нормы и отправил «В приложение» или в Max — в это воскресенье автоматическое не уходит (ставится пропуск). То же, если тренер с четверга по воскресенье отправил клиенту любое своё ДЗ «В приложение».

**Неделя блока** считается от воскресенья включения (`anchor_date`): 1, 2, 3, 4, потом новый блок с другим набором упражнений. Пропущенное воскресенье неделю не «замораживает» — блок идёт по календарю.

**Безопасность:** если в карточке здоровья есть болезни или противопоказания, а «Нельзя при» пусто, задание само не уходит. На экране жёлтое предупреждение с текстом из карточки («Грыжа L5»), строка «Нельзя при» подсвечена; тренер отмечает ограничения или жмёт «Ограничений для дома нет». Если заполнена **анкета здоровья**, правило другое: при красных метках задание ждёт «Допуск подтверждён», а зоны тела и уточнения сами добавляют ограничения, уровень 1 и «без прыжков» при каждой сборке — [HEALTH_SCREENING.md](./HEALTH_SCREENING.md).

**Сервер:** cron на ВМ каждые 15 минут (`scripts/client-reminders-vm.mjs` → `runHomeworkAutoSend`), работает в воскресенье 10:00–22:00 МСК. Для каждого включённого клиента — та же сборка, что у тренера (`buildHomeworkAutoPlan`), запись в `client_plans` от имени тренера клиента и push «Тренер Анна: новое задание». `id` задания постоянный от клиента и даты — повторный запуск ничего не дублирует. Архивным не уходит.

Код — `src/lib/homework/auto/homeworkAutoScheduleCore.js` (неделя, причины паузы, права, сборка), `homeworkAutoService.js` (сохранение на планшете), `api/_lib/homeworkAuto/homeworkAutoJob.js` (cron), экран — `HomeworkAutoScheduleCard.jsx` + `useHomeworkAutoSchedule.js`. Таблица `homework_auto` — [DATA_MODEL.md](./DATA_MODEL.md), sync — [SYNC.md](./SYNC.md). Проверка — `scripts/verify-homework-auto.mjs`.

**Пока не умеет:** инвентарь клиента (все упражнения считаются доступными: резинка — стандарт, у гантелей подсказка замены); уровень сам не растёт — тренер переключает. Питание по воскресеньям — [NUTRITION_AUTO.md](./NUTRITION_AUTO.md).

## Библиотека (шаг 0)

113 упражнений: уровни 1–2 и три безопасных упражнения уровня 3. Названия — простыми словами (жаргон — в скобках). Основная аудитория — женщины: больше упражнений на ягодицы и внешнюю сторону бедра (отведения ноги, ракушка, мост с резинкой, реверанс, сумо), руки и плечи — с резинкой, без единоборств. Убраны опасные без тренера рядом, дубли и малополезные (вакуум, «складка», подъём прямых ног, бой с тенью и т. п.).

Код — `src/lib/homework/library/`: словарь меток `homeworkLibraryTags.js`, упражнения по группам (`libraryLegs.js`, `libraryUpper.js`, `libraryCore.js`, `libraryCardio.js`, `libraryMobility.js`), сборка и правила — `homeworkLibrary.js`: отбор под клиента `filterHomeworkLibrary`, часть занятия `homeworkEntryPhases`, подсказка к гантелям `homeworkDumbbellNote`. Библиотека одна на все клубы.

### Правка библиотеки админом

**Кто:** только админ сети. Админка → Структура → вкладка **«Библиотека ДЗ»**. Тренер библиотеку не меняет, но генератор у него берёт уже исправленную.

**Что можно:** найти упражнение (поиск, фильтр по движению), **изменить** любое поле (название, движение, уровень, цели, часть занятия, «нельзя при», инвентарь, повторы/секунды, «на каждую сторону», прыжки, как выполнять, главная ошибка), **добавить своё**, **убрать из подбора** и **вернуть**. У изменённого встроенного есть кнопка «Вернуть как было». Пометки в списке: «Изменено», «Своё», «Убрано». Форма проверяет те же правила, что и встроенные упражнения (у гантелей — домашняя замена и упражнение без гантелей того же движения; прыжки — с уровня 2 и с ограничением «Колени»), ошибки — у поля, по-русски.

**Как устроено:** 113 встроенных упражнений остаются в коде. В таблице `homework_library` — только правки: строка с id встроенного = изменение, новый id `c_xxxxxxxx` = своё упражнение, `is_active = false` = убрано (строку не удаляем, поэтому всегда можно вернуть). Итоговая библиотека = встроенная + правки (`mergeHomeworkLibrary`). Её берут и вкладка «Авто» на планшете, и воскресный cron — одно правило. Уже отправленные задания не меняются: в `client_plans` хранится снимок.

**Когда дойдёт до тренера:** правка уходит на сервер сразу; на планшет — со следующим Sync (`trainer-pull` отдаёт `homework_library`). Cron по воскресеньям читает таблицу напрямую, поэтому до Sync предпросмотр тренера может чуть отличаться от того, что уйдёт. Если таблицы ещё нет (миграция не применена), всё работает на встроенной библиотеке.

Код — `homeworkLibraryOverridesCore.js` (слияние, статусы, права), `homeworkLibraryFormCore.js` (форма ↔ упражнение, ошибки), `homeworkLibraryService.js` (сохранение через очередь sync, pull для админки), хук `src/hooks/useHomeworkLibrary.js`, экран — `src/pages/admin/AdminHomeworkLibrary.jsx` + `HomeworkLibraryEntryForm.jsx`; сервер — `api/_lib/homeworkLibrary/`. Проверка — `scripts/verify-homework-library-overrides.mjs`, экран — сценарий `adminHomeworkLibrary.mjs`.

| Поле | Смысл |
|---|---|
| `pattern` | Тип движения: присед, выпады, наклон, ягодицы, голень, толчок, тяга, кор, кардио, мобильность, растяжка |
| `phases` | Часть занятия; по умолчанию из `pattern` (`homeworkEntryPhases`), явно — только исключения |
| `level` | 1 новичок · 2 средний · 3 продвинутый |
| `equip` | Без инвентаря · опора (стул, диван) · резинка · гантели |
| `household`, `alt` | Только у гантелей: подручная замена («бутылки с водой по 1,5 л») и упражнение без гантелей того же типа движения, не добавляющее ограничений |
| `unit`, `side` | Повторы или секунды; «на каждую сторону» |
| `impact` | Прыжки — только с уровня 2, всегда с ограничением «колени»; без явного разрешения не подбираются |
| `avoid` | Нельзя при: поясница, колени, плечи, запястья, давление — **жёсткий фильтр** |
| `goals`, `focus` | Какие цели закрывает; акцент: низ / верх / кор / всё тело |
| `how` | Как выполнять простыми словами: исходное положение и движение (1–2 предложения, до 220 символов) |
| `cue` | Главное в технике — частая ошибка (до 100 символов) |

**Безопасность:** ограничения клиента отсекают упражнение жёстко. Если в карточке есть болезни или противопоказания, а ограничения не заполнены, авто-ДЗ не уходит само, пока тренер не подтвердит (шаг 2).

**Проверка:** `scripts/verify-homework-library.mjs` — корректные метки и замены гантелей, уникальные id и названия; у каждой цели, каждого ограничения и каждой части занятия новичку остаётся выбор.

**Просмотр тренером:** `node scripts/export-homework-library.mjs` → `homework-library.csv` (Excel). Метки подтвердить у тренера клуба до запуска шага 2.

**Дальше (не в шаге 0):** картинка или короткое видео к каждому упражнению — без них клиенту сложно выполнить незнакомое движение.
