# ИСКРА Pro — модуль внутри FIT-CITY

**Версия:** 2026-07  
**Горизонт:** первый год — **внутри приложения**, не отдельный домен.

---

## Что это

**ИСКРА Pro** — коммерческая упаковка управленческого модуля FIT-CITY для собственника и руководителя клуба:

| Компонент | Зачем |
|-----------|--------|
| **ИСКРА** | План, риски, советы Gemini, playbooks НК/ДК/УК/ПЗ |
| **Планёрка** | Задания тренерам и менеджерам без Telegram |
| **База знаний** | Ответы «как в приложении» |
| **ИСКРА-Куратор** | Куратор сети: KPI + личное расширение — [ISKRA_CURATOR.md](./ISKRA_CURATOR.md) |
| **Два контура в клубе** | Продажи и Тренеры (планшеты) — раздельно |

---

## Уровни зрелости (roadmap)

| Уровень | Срок | Содержание |
|---------|------|------------|
| **L1 — Pro в FIT-CITY** | 0–3 мес | Полная ИСКРА для `app_admin`, Планёрка v1, KB, seed playbooks |
| **L2 — Клуб и роли** | 6–12 мес | Управляющий, мульти-клуб, **ИСКРА-Куратор** (личный) |
| **L3 — Standalone** | 12+ мес | Отдельный вход, если snapshot API стабилен |

Сейчас реализуем **L1**.

---

## L1 — что входит (технически)

### ИСКРА (аналитика)

- Сегменты **Продажи | Тренеры** с жёсткими границами данных
- Gemini **Стандарт / Подробно** без лимитов для админа
- Отраслевые playbooks (НК/ДК/УК/ПЗ) + клубные уроки
- База знаний `docs/iskra-kb/` + `iskraKnowledgeBaseCore.js`
- Утренний бриф, карточки, чеклист недели

### Планёрка (операции)

- Назначить из карточки ИСКРЫ / чеклиста
- Экран **Задания клуба** (`/admin/club-tasks`)
- Inbox тренера в шапке планшета
- **Лента статусов в панели ИСКРЫ** — активные и недавно выполненные

### Не в L1

- Авто-задания по триггерам (v2)
- KPI-рейтинг тренеров
- Отдельный лендинг и биллинг Pro

---

## Ценность для клуба (одна фраза)

> ИСКРА видит дыру в плане по отчёту менеджера — Планёрка доводит до тренера — статус виден в панели без Telegram.
