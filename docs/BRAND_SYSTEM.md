## 0. Продукт ≠ клуб (обязательно)

| Слой | Имя | Где |
|------|-----|-----|
| **Продукт (SaaS / ОС)** | **Ядро** (UI везде) · `CORE` (код) | Splash, PWA, title; в шапке — **только микро-знак** (шевроны) + aria/title |
| **Клуб (тенант)** | **FIT-CITY** и другие | **Герой шапки** (крупно), chip, селект, отчёты |
| **ИСКРА** | AI-модуль | Кнопка / панель, не имя ОС |
| **Репозиторий** | `fitness-diary` | GitHub |

**Иерархия в зале:** клуб громче продукта. Ядро «горит» на входе (splash) и в PWA; каждый день слева — имя клуба.

**Правило:** название клуба не подменяет Ядро в splash/PWA/продаже SaaS. В ежедневной шапке наоборот: клуб — title, Ядро — тихий знак онлайн/офлайн.

Смена имени продукта = только [`src/lib/productBrand.js`](../src/lib/productBrand.js), затем:

```text
npm run sync:brand    # index.html, manifest, lockup SVG
npm run gen:icons     # = sync + иконки PWA
node scripts/verify-product-brand.mjs
```

В UI **не** хардкодить имя продукта — только `PRODUCT_BRAND_*` / хелперы из `productBrand.js`. Docs (BRAND / vision / handoff) обновить вручную кратким поиском по старому имени.

Смена имени продукта = `productBrand.js` + sync/icons/verify + этот документ + PWA.

## 1. Суть и коммерческая цель

**Одна фраза:** Ядро — тёмная премиальная операционная система фитнес-клуба: спокойный фон, цифры и следующий шаг в центре, редкий яркий CTA.

| Контекст | Что должно чувствоваться |
|----------|---------------------------|
| Презентация / продажа клубу | «Покупаем Ядро»; FIT-CITY — пример внедрения |
| Тренер на планшете | Крупно клуб; знак Ядро мелко (онлайн/офлайн) |
| Админ / менеджер | Тот же продукт, ролевой нюанс цвета |

Красота **не имеет права** ухудшить touch (≥44px), увеличить число тапов или спрятать ошибку sync/офлайн.

## 3. Опора: Whoop (дисциплина, не копия)

**Опорная компания:** Whoop — тёмный canvas, данные в центре, цвет = смысл, редкий яркий CTA.

| Берём | Не берём |
|-------|----------|
| Near-black, мало декора | Логотип и ассеты Whoop |
| Цвет = смысл | Indigo/violet как primary CTA |
| Редкий яркий CTA | Чужие шрифты и пиксели |

**Формула:** *«как Whoop по дисциплине, но ОС фитнес-клуба Ядро»*.

## 5. Ролевые цвета

Оттенок = **кто залогинен**, не модуль. Админ на продажах остаётся champagne.

| Роль | Нюанс | Bright | Solid | Dim |
|------|--------|--------|-------|-----|
| Тренер | Emerald | `#2effb8` | `#14d89a` | `#0a7d5c` |
| Менеджер | Cyan–teal | `#22d3ee` | `#06b6d4` | `#0e7490` |
| Админ | Champagne | `#f0d48a` | `#d4b45c` | `#8a7340` |

Красим: accent, radial, glow, mark, nav underline.  
Не красим: text, danger, warning, радиусы, типографику целиком.

## 7. Типографика, поверхности, компоненты

| Уровень | Назначение | Плотность |
|---------|------------|-----------|
| Hero / splash | Имя продукта, вход | Крупно, воздух |
| H1 экрана | Один заголовок задачи | Зал крупнее |

**Layout:** зал — крупные тапы ≥44px; админ — плотнее цифры; master–detail ≥1100px для ПНК.  
**Запрет:** сырые hex в новом UI; indigo/violet как primary; светлая тема v1.

## 9. Critic-чеклист

1. Красиво на слайде и удобно на планшете?  
2. Тапы / ≥44px / читаемость с 60 см?  
3. Премиум без glow-казино?  
4. Три роли за ~2 сек по шапке/accent?  
5. Админ на продажах = champagne (не cyan)?  
6. Не казино / purple?  
7. Один главный CTA на экран?  
8. Цвет = смысл?  
9. Empty / loading / error того же класса?  
10. «Как Whoop по дисциплине, но ОС клуба Ядро»?  
11. На экране нигде продукт не назван FIT-CITY?

## Приложение A — Driving prompt

```text
Роль
Ты — жёсткий дизайн-директор коммерческого B2B-продукта Ядро (код CORE)
для фитнес-клубов. FIT-CITY — название клуба-тенанта, НЕ продукта.
Не декоратор и не «сделай красивее». Цель: продукт продаётся на презентации
собственнику клуба и удобен тренеру на планшете без лишних тапов.

Продукт (истина)
- Имя UI: Ядро (src/lib/productBrand.js). Локкап: ЯДРО. Марка: OsMark.
- PWA: тренер офлайн-first; админ/менеджер на мониторе; ИСКРА — надстройка, не вторая палитра.
- Канон: docs/BRAND_SYSTEM.md. Опора: Whoop (дисциплина тёмного canvas / данные / редкий CTA).
- Не копировать лого, пиксели, шрифты Whoop. Формула: «как Whoop по дисциплине, но ОС клуба Ядро».
- Роли (оттенок = кто залогинен, не модуль):
  тренер emerald; менеджер cyan-teal; админ champagne.
  Админ на продажах/ПНК остаётся champagne.

Цель каждого ответа
1) Держать продукт ≠ клуб (FIT-CITY никогда не подменяет Ядро в brand-mark).
2) Коммерческая красота без вреда UX зала (touch ≥44px, sync-ошибки видимы).
3) Один визуальный язык: токены, не сырые hex.

Обязательный разбор
A — какие плюсы усиливаем (Whoop-класс, 3 роли на слайде, скорость CTA)
B — какие минусы закрываем (glow-казино, admin=trainer, admin синеет, путаница клуба)
C — ответы на critic-вопросы §9 (все пункты)
D — что берём / не берём у Whoop в этом решении

Critic (кратко)
1 слайд vs планшет · 2 тапы/44px · 3 премиум без glow · 4 три роли за 2 сек
5 admin на продажах = admin · 6 не казино/purple · 7 один CTA · 8 цвет=смысл
9 empty/loading/error одного класса · 10 «как Whoop, но Ядро»
11 продукт нигде не назван FIT-CITY?

Запреты
Ломать sync/офлайн; три UI-языка на одну воронку; сырые hex; кнопки <44px;
копировать ассеты Whoop; путать клуб и продукт; violet/indigo primary.

Вердикт в конце: Делаем / Упростить / Отложить / Не делаем.
```
