# Переписка клиента с тренером и клубом

**Актуально:** 2026-10-11  
**Статус:** ✅ в проде с 11.10.2026 (коммит `de66703`, миграция `20261011120000_client_chat.sql` применена).

## Ситуация

- Клиентка находит резинку на Wildberries и шлёт тренеру ссылку в личный мессенджер. Переписка живёт в телефоне тренера: клуб её не видит, при смене тренера история теряется.
- «Можно заморозить абонемент?» уходит кому придётся — в личку менеджеру, в общий чат, на стойку.
- Жалоба на зал доходит до управляющего пересказом через третьих лиц.

**К цели:** общение с клиентом — часть CRM клуба. История привязана к настоящему клиенту в Ядре и принадлежит клубу, а не личному телефону сотрудника.

## Как пользоваться

**Клиент:** конверт в шапке `/me` (число = непрочитанные диалоги + рассылки) → «Сообщения» (`/me/inbox`). Сверху три диалога: «Тренер · Анна», «Менеджер по продажам», «Управляющий»; ниже «Объявления и опросы». Диалог → `/me/chat/:kind` → лента и поле ввода. Ссылки в сообщениях кликабельны. Без назначенного тренера диалога «Тренер» нет.

**Тренер / менеджер продаж / управляющий:** тот же конверт «Сообщения клуба» в шапке (число = рассылки + непрочитанные диалоги) → `/messages` → вкладка «Диалоги с клиентами» (`/messages?tab=chats`), непрочитанные сверху → диалог `/messages/chat/:clientId/:kind`. Из карточки клиента — строка «Переписка:» с кнопками диалогов, доступных роли.

**Вид — как в Telegram:** плашки дней («Сегодня», «Вчера», «9 октября»); подряд идущие сообщения одного автора (до 5 минут) — одной пачкой, «хвостик» у последнего пузыря; время и галочки внутри пузыря (✓ — отправлено, ✓✓ — собеседник открыл диалог); сообщение из 1–3 смайликов — крупно, без пузыря. Поле ввода — капсула с кнопкой смайликов (наборы «Эмоции», «Жесты», «Спорт», «Питание» + «Недавние» на устройстве) и круглая кнопка «Отправить». На компьютере Enter отправляет (Shift+Enter — новая строка), на планшете и телефоне Enter — новая строка; Ctrl/Cmd+Enter отправляет везде. **Стикеры клуба** (клиент и сотрудник): вкладка «Стикеры» в той же панели, нажатие — сразу отправка. 12 стикеров с персонажем клуба — Гирькой (гиря с лицом, руками и ногами, своя эмоция и поза в каждом) — как в Telegram: белая «вырезная» обводка, анимация при появлении (3 раза; нажатие — ещё раз; в панели — при наведении; «уменьшение движения» на устройстве — без анимации). Векторные, на цветах бренда (перекрашиваются с темой клуба), с подписью. «По делу»: «Опаздываю ~10 минут», «Сегодня не смогу», «Буду!», «Перенесём?», «Жду на тренировке», «Спасибо!». «Настроение»: «Рекорд!», «Огонь!», «Сделано!», «Устал, но сделал», «Пей воду», «Отличная работа». В сообщении хранится только id стикера из списка `chatStickerCore.js`, текст сообщения сервер берёт из подписи — её видят push и превью в списке. Чужой id — 400; неизвестный старой версии приложения стикер показывается текстом.

Список диалогов — круглая аватарка с инициалами (или значок «Менеджер» / «Управляющий»), время справа, число новых в кружке.

**Главный админ:** конверта нет; читает переписку из карточки клиента («Переписка: Тренер / Менеджер по продажам / Управляющий»).

**Push:** клиент написал → тренеру (диалог «Тренер»), всем менеджерам продаж клуба («Менеджер по продажам») или управляющим клуба («Управляющий»). Сотрудник ответил → клиенту. Тихие часы 22:00–9:00 — без push, сообщение ждёт в ленте. Нажатие на push открывает сам диалог.

## Правила доступа

| Диалог | Пишет | Читает |
|---|---|---|
| Тренер | текущий тренер клиента (`clients.trainer_id`), главный админ | они же |
| Менеджер по продажам | любой менеджер продаж клуба клиента, управляющий клуба, главный админ | они же |
| Управляющий | управляющий клуба клиента | он же + главный админ (только читает) |

- Тренер не видит диалоги с менеджером и управляющим; менеджер — с тренером и управляющим. Пустая или чужая роль — 403. Менеджер / управляющий без клуба — 403.
- Смена тренера: новый тренер видит всю историю, прежний теряет доступ (доступ — по текущей строке клиента).
- Клиент в архиве: историю читать можно, писать нельзя (входа в приложение у него нет).
- «Прочитано» у сотрудников общее на диалог: открыл один менеджер — у остальных менеджеров клуба тоже прочитано.
- Только текст до 2000 символов; фото, голос и файлы — нет.
- Офлайн: писать нельзя — «Нет сети — сообщение не отправлено», текст остаётся в поле. Очередь sync не участвует.
- Пока диалог открыт и виден — новые сообщения подтягиваются раз в 10 с; иначе — push и опрос конверта раз в 2 минуты. Постоянного соединения нет (переносимо между хостингами).

## Как устроено

- Таблицы: `chat_threads` (один диалог на `(client_id, kind)`; `last_message_at`, `last_author`, `last_preview`, `client_read_at`, `staff_read_at`, счётчики `client_unread` / `staff_unread`), `chat_messages` (`author_side`, `author_client_id` / `author_user_id`, `body`, `sticker`). Только сервер, RLS без политик — [DATA_MODEL.md](./DATA_MODEL.md).
- API: `/api/client-me` POST `chat-list` / `chat-thread` / `chat-send` (+ `chat_attention` в GET) и `admin-data?action=chat` — [API.md](./API.md).
- Правила (без React и базы): `src/lib/chat/chatAccessCore.js` (кто читает / пишет, кому push, «непрочитано», число новых, когда прочитал собеседник), `chatMessageCore.js` (текст, превью, склейка ленты, ссылки, время), `chatFeedCore.js` (плашки дней, пачки, галочки, крупные смайлики), `chatEmojiCore.js` (наборы смайликов, вставка в позицию курсора, «Недавние»), `chatStickerCore.js` (набор стикеров, проверка id, текст = подпись), `chatUiCore.js` (подписи, инициалы, кружок с числом).
- Сервер: `api/_lib/chat/` — `chatStore.js` (запросы), `chatConversation.js` (открыть / отправить — общее для клиента и сотрудника), `chatClientHandler.js`, `chatStaffHandler.js`, `chatPushJob.js` (подписки — `loadSubscriptions` из `inbox/inboxPushJob.js`).
- Экраны: общие `src/components/chat/` (`ChatThreadView` — склейка ленты и поля, `ChatFeed` — пузыри, `ChatComposer` — поле ввода, `ChatEmojiPicker` — панель смайликов и стикеров, `stickers/` — Гирька (`StickerKettle.jsx`: лицо, руки, ноги), сцены (`chatStickerShapes.jsx`), рамка с обводкой (`ChatSticker.jsx`) (стили `src/styles/chat-stickers.css`), `ChatThreadList` — строки диалогов, `ClientChatLinks` — «Переписка» в карточке клиента), хук ленты `src/hooks/useChatThread.js`; клиент — `src/pages/client/ClientChatPage.jsx`, `ClientChatThreadsSection.jsx`, `useClientChat.js`, `src/lib/client/clientChatService.js`; сотрудник — `src/pages/staff/StaffChatList.jsx`, `StaffChatThread.jsx`, `src/hooks/useStaffChat.js`, `src/lib/chat/staffChatApiClient.js`. Стили — `src/styles/chat.css`.
- Проверка: `node scripts/verify-chat.mjs`; экран — сценарий «переписка: клиент пишет, тренер отвечает» в `npm run qa:screens`.

## Выкатка
