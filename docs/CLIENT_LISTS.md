# Списки клиентов (замена выгрузок 1С)

**Статус:** ✅ MVP в коде (экран без Excel).  
**Актуально:** 2026-11-01.

## Зачем

Менеджер / админ собирает рабочий список «кому звонить» из правды Ядра: зал(ы), живые или архив, дни рождения, истекающий / недавно истёкший абон — без утренней выгрузки из 1С.

## Где в продукте

| Роль | Путь | Вход |
|------|------|------|
| Админ | `/admin/client-lists` | Клиенты → иконка «Списки» |
| Менеджер | `/sales/client-lists` | то же |
| Управляющий | `/club/client-lists` | то же |

Данные — локальный кэш клиентов / абонов / lifecycle клуба (как вкладка Клиенты). Кнопка обновления тянет облако тем же контуром.

## MVP (фаза 1)

- Пул: **Живые** | **Архив**
- Залы: ПЗ / ТЗ / АЗ (несколько — OR)
- Признак: все по залу | дни рождения (сегодня / 7 / 14 / 30 дн.) | истекает | недавно истёк
- Архив: период по `archived_at` (с… по…)
- Результат на экране: ФИО, карта, телефон, залы → карточка. **Без Excel.**
- Фильтры в URL; с карточки «назад» (`from=lists`) возвращает в тот же конструктор.
- «Назад» к Клиентам в шапке; обновление из облака не гасит уже показанный список.

Логика: [`src/lib/admin/clientListsQueryCore.js`](../src/lib/admin/clientListsQueryCore.js).  
Возврат: `from=lists` в [`clientCardReturnCore.js`](../src/lib/admin/clientCardReturnCore.js).  
Verify: `node scripts/verify-client-lists-query.mjs`, `node scripts/verify-client-card-return.mjs`.

Не путать с чипом «Не активные» (конец воронки абона) и с [`/admin/excel-lists`](./SALES_MANAGER.md) (импорт **из** 1С в desk).

## Чеклист сверки с 1С (операционка зала)

| # | Выгрузка в 1С | В Ядре сейчас |
|---|----------------|---------------|
| 1 | Клиенты по залу / типу карты | ✅ вкладки + конструктор залов |
| 2 | Заканчивающиеся абонементы | ✅ признак «Истекает» |
| 3 | Ушедшие / архив за период | ✅ Архив + даты |
| 4 | Дни рождения | ✅ признак ДР |
| 5 | Не посещали N дней | ⏸ backlog (пауза визитов ≠ funnel inactive) |
| 6 | Новые за период | ⏸ |
| 7 | Продажи / продления | ✅ отчёт дня + Стратегия |
| 8 | Должники / заморозки | ⏸ нет домена |

Касса / DDS / налоговые отчёты — **не** в этом экране ([PRODUCT_VISION.md](./PRODUCT_VISION.md)).

## Backlog

- **Фаза 2:** Excel / CSV наружу (мост для SMS / бумаги), не правда.
- **Фаза 3:** «Взять в работу» → Стратегия / УК / обзвон (точный добор из архива к плану продлений).
- Пауза «не был N дней» по визитам ПЗ/АЗ — отдельный признак, когда согласуем источник для ТЗ.
