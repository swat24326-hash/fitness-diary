## 1. Купить домен (только владелец)

1. Войти в [reg.ru](https://www.reg.ru) или nic.ru **под ИП** (как Yandex Cloud).  
2. Зарегистрировать **`app-core.ru`** на 1 год (часто ~169 ₽ первый год; перед оплатой ещё раз проверить «свободен»).  
3. Запасные, если вдруг заняли: `myappcore.ru`, `getyadro.ru` / `os-kluba.ru` — сначала напишите в чат.  
4. Подтвердить личность через **Госуслуги** («Заполнить через Госуслуги», вариант для ИП) — без этого `.ru` не работает и DNS на ВМ не прописать. ОКВЭД для покупки не нужен.  
5. **Не** привязывать к Vercel и **не** менять прод до «стартуем R3…».  
6. В чат: `домен куплен: app-core.ru`.

До ночи достаточно: домен ваш, NS у регистратора по умолчанию. A-запись на ВМ — в §3.

### 3b. DNS у регистратора

- [ ] Тип **A**: хост `@` → публичный IP ВМ.  
- [ ] Опционально `www` → A или CNAME на `@`.  
- [ ] Проверка: `nslookup app-core.ru` → IP ВМ.

### 3c. HTTPS (Let's Encrypt)

1. Reverse-proxy 80/443 → приложение (часто :8080).  
2. `certbot` (или Caddy) для **`app-core.ru`**.  
3. Редирект http → https.  
4. В браузере: замок, открывается приложение.

### 3d. Env и сборка

- `PUBLIC_ORIGIN=https://app-core.ru`  
- `HOST=0.0.0.0` (как принято на ВМ)  
- C2 на проде: `AUTH_PROVIDER=own`, `DATA_BACKEND=pg` — по runbook волны 3.  
- Пересборка при необходимости + рестарт.

Проверка: `https://app-core.ru/api/health` → ok; вход; Закончить → Sync → админка.
