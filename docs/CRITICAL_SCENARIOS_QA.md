# Критические сценарии — план проверки

**Актуально:** 2026-08-26  
**Статус:** рабочий чеклист + автопрогон `npm run qa:critical`  
**Политика:** `.cursor/rules/fitness-diary-stability.mdc`, [TESTING.md](./TESTING.md)

Не дублирует полный `qa:local`. Это **обязательный контур «не сломать зал и админку»** после правок sync / абон / главная / call-центр / клиенты.

---

## 1. Как пользоваться

| Когда | Команда |
|-------|---------|
| После правки критического пути | `npm run qa:critical` |
| Перед деплоем (быстро) | `npm run qa:critical` → при зелёном деплой |
| Перед крупным релизом | `npm run qa:local` (полный) + ручной §3 |
| Только автоблок без lint | `node scripts/qa-critical.mjs --skip-lint` |

Ручные шаги (§3) — на планшете/проде, когда трогали complete / Sync / главную.

## 3. Ручной чеклист (планшет / прод)

Делать после правок complete / Sync / PWA / главной. Отмечать ✅/❌.

### Зал (тренер)

1. Офлайн: новая тренировка → упражнения → **Закончить** → абон списался, в очереди есть запись.
2. Online: **Sync** → очередь ушла, тренировка на другом устройстве/в админке видна.
3. Открыть завершённую → сменить дату → сохранить → Sync → дата не откатилась.
4. Два быстрых тапа «Закончить» — одна запись completed, без зависания «Сохраняем…».
4a. Черновик: набрать текст → главная → снова открыть — текст/упражнения на месте (не «су»).
4b. Карточка клиента → Тренировки → **Удалить** черновик → **Да** — карточка и вкладки черновиков пустые; после reload не возвращается.
4c. Слабая сеть / 2–3 клиента подряд: завершить или сохранить → сразу открыть карточку другого, вернуться — дневник первого **не пустой**; после Sync при нормальной сети очередь уходит.
4d. **Сплит вкладок:** два черновика (Шалаева + Крофта) — заполнить упражнения у первого → вкладка второго → заполнить → вернуться к первому — упражнения и направленность **на месте**; подождать «Сохранено» перед быстрым переключением.

### Админка / клуб

5. Главная `/admin?club=…`: при слабой сети через ~8–12 с **не** вечный скелетон; сводка дня с цифрами из кэша или ошибка текстом.
6. Сводка смены: **4 плитки** (звонки / SMS / перезвонить / закрыто), даже при нулях.
7. Клиенты: вкладки ПЗ → ТЗ → АЗ, поиск cross-hall, карточка открывается.
8. Call: журнал звонка → пометка «перезвонить» с датой МСК.

### ИСКРА / статистика (если трогали agg)

9. Статистика клуба открывается, KPI не «NaN».
10. ИСКРА отвечает на простой вопрос по клубу (без выдуманных оплат).
