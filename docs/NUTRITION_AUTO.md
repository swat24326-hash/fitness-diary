# Авто-питание клиенту (воскресенье + вес)

**Актуально:** 2026-10-17. Статус: 🔧 в репо (шаг 1 — воскресный пересчёт КБЖУ при смене веса ≥ 3 кг и отправка в приложение).

## Ситуация

Тренер ведёт десятки клиентов с рационом. Вес меняется, граммы устаревают; руками пересчитать и нажать «В приложение» он не успевает. Клиент в `/me/nutrition` ест по старым порциям.

## Решение (как у авто-ДЗ, [HOMEWORK_AUTO.md](./HOMEWORK_AUTO.md))

| Вопрос | Решение |
|---|---|
| Когда | То же окно, что у авто-ДЗ: **воскресенье 10:00–22:00** по часам клуба (cron каждые 15 мин) |
| Что делает | Пересчитывает КБЖУ (**те же блюда**, новые граммы) и шлёт снимок в `client_plans` |
| Условие | Вес сменился на **≥ 3 кг** относительно `plan.basis.weightKg` (или рост — план «устарел») |
| Включение | Галочка / переключатель на экране питания → `nutrition_survey.nutritionAutoPush` |
| Паузы | Архив; нет рациона; вес почти не изменился; тренер сам отправил рацион чт–вс; «пропустить» это воскресенье |
| Push тренеру | После успешной авто-отправки — «Рацион ушёл из‑за веса» (имя + на сколько кг), тап → карточка клиента, вкладка «Питание» |

## Что видит тренер

На экране питания — карточка **«Каждое воскресенье»**: включил — клиент получит пересчёт сам, когда вес уйдёт на 3 кг и больше. Подпись: сколько кг изменилось, уйдёт ли в ближайшее воскресенье или почему нет. Кнопка «Пропустить Вс …».

Когда cron отправил рацион — тренеру push (даже если карточку давно не открывал): контроль без рутины, сразу в карточку клиента.
