# Академия (обучение) — отдельный сервер + мост в Ядро

**Актуально:** 2026-10-02  
**Статус:** 📋 решение владельца; **код после** недели мониторинга R3 и §5.7 security ([PATH_TO_GOAL.md](./PATH_TO_GOAL.md) §4, ставка 4c).  
Репозиторий Академии — отдельный: `fitnes-academy` (свои правила и docs, план переезда — его `docs/STACK-MIGRATION.md`, фаза R).

## Ситуация

- Академия — обучение сотрудников клуба: разделы, тесты, рейтинг, админка. Сейчас Vercel + Firebase (Auth, Firestore), тариф Spark.
- Картинки в учебные блоки не добавить: Firebase Storage для новых проектов требует платный тариф (иностранная карта).
- Обучение проходят и **кандидаты** — ещё не сотрудники: пришёл → обучился → нанят.
- Управляющему нужно видеть результаты обучения в Ядре (карточка тренера, найм).

## Решение (владелец 2026-10-02)

| Что | Как |
|-----|-----|
| Хостинг | Отдельный недорогой российский VPS (не ВМ клуба) — Академия не может уронить зал |
| Данные | Свой Postgres на этом VPS (вместо Firestore), картинки — на диске VPS |
| Вход | Свой вход Академии (вместо Firebase Auth); кандидаты и сотрудники |
| Связь с Ядром | **Мост только на чтение:** сервер Ядра запрашивает у Академии результаты сотрудника и показывает в карточке |
| Бэкап | Не критичен (контент почти не меняется) — достаточно лёгкой периодической копии базы |

Отвергнуто: Академия внутри Ядра (общий логин и роль «Кандидат») — меньше изоляции для зала; владелец выбрал отдельный сервер.

## Мост — требования безопасности

- HTTPS + секретный ключ сервер-сервер (только server env, не `VITE_*`) + allowlist IP сервера Ядра.
- Запрос идёт **с сервера Ядра**, не из браузера; Академия отдаёт только результаты обучения, без лишних персональных данных.
- В Ядре — новый `admin-data?action=` (или аналог), с `requireAdmin` / роль управляющего; эндпоинт Академии — read-only.
- Связка аккаунтов: при найме — «привязать к сотруднику» (по телефону / логину); без привязки данные кандидата в Ядро не попадают.
- Кандидаты — не сотрудники: согласие на обработку персональных данных (152-ФЗ) при регистрации.

## Порядок

1. **Сейчас (в репо Академии, Ядро не трогает):** картинки — временно Yandex Object Storage через серверную функцию с проверкой админа; при переезде перенести на VPS скриптом.
2. После §5.7: VPS → API + Postgres + вход → миграция данных из Firestore → выключить Firebase (фаза R Академии).
3. Мост в Ядро: результаты в карточке тренера.
