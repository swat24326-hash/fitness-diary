# Пульс в общей шапке

**Статус:** ✅ MVP в коде (Chrome / Edge на Android-планшете).  
**Не путать с:** «Пульс команды» / Планёрка ИСКРЫ.

## Зачем

Тренер надевает BLE-датчик на клиента. Живой пульс — в **общей шапке**. На шаге **Итог** — сводка сессии (ср./мин/макс, зоны, оценка ккал), она сохраняется в дневник тренировки (`data.hr_session`) и уезжает Sync.

**Сплит:** до **двух** датчиков. Один чип — только BPM; два — фамилия + BPM.  
Цвет чипа — по зоне ЧСС (нужна дата рождения). При обрыве связи — чип «Снова».

## Как пользоваться

1. Тренировка → иконка пульса у имени → датчик.
2. Пульс в верхней шапке (тап по чипу — отключить; при потере связи — «Снова»).
3. В упражнениях формата **Функциональная** / **Кардио** — ячейка «Пульс» в подходе: **двойной тап** подставляет текущий BPM с датчика. В режиме **Л/П** — две строки (Л сверху, П снизу), у каждой свой пульс и **RPE**; **одна** корзина на обе стороны.
4. На шаге **Итог** — блок «Пульс сессии».
5. «Закончить тренировку» — снимок в дневник, живой пульс этой сессии гаснет.
6. В карточке клиента → **Тренировки** → глаз: тот же снимок в просмотре (ср./мин/макс, зоны, ккал).

Если в карточке нет ДР / пола / веса — на странице тренировки подсказка «сводка неполная» (зоны и ккал могут быть без цифр).

Зоны: лёгкая &lt;60% / средняя 60–80% / высокая ≥80% от макс. ЧСС ≈ 220 − возраст (нужна ДР).  
Ккал: оценка Keytel (нужны пол в карте здоровья и вес). Подпись «оценка».

## Устойчивость

| Ситуация | Поведение |
|----------|-----------|
| Краткий обрыв GATT | Чип `lost` + «Снова»; буфер сэмплов **не** обнуляется |
| Переподключение того же клиента | Сэмплы продолжаются |
| Reload вкладки | Сэмплы в `sessionStorage` **этой** тренировки — сводка на «Итоге» может восстановиться |
| Удалили черновик при живом датчике | Буфер этой тренировки сбрасывается; BLE **остаётся** (можно сразу начать новую) |
| **Новая** тренировка (`/workouts/new`) | Новый scope буфера (trainingId); чужой хвост клиента не попадает на Итог |
| «Закончить тренировку» | Снимок в `hr_session`, буфер очищается, чип этого клиента **снимается** (датчик не пишет в завершённую). Следующая тренировка — снова иконка пульса |
| Завершённая тренировка | На Итоге только сохранённый `hr_session`, не живой буфер; открытие завершённой **не** продолжает запись |
| Черновик без датчика | Блок «Пульс сессии» скрыт (нет сэмплов этой тренировки; старый буфер v1 сбрасывается) |
| Новая → первое сохранение | Scope `pending` → uuid тренировки (migrate + flush RAM) |
| Reload mid-draft | Сэмплы по ключу этой тренировки; повторный load не создаёт новый pending |
| Две тренировки одного клиента | Буферы изолированы |
| Длительность сводки | Только окно последних **4 ч** сэмплов (иначе «минуты» раздуваются от старых точек) |
| Датчик не в фильтре Heart Rate | Второй пикер `acceptAllDevices` |
| Повторный вход к клиенту | Предпочтение deviceId из карты client↔device |

## Требования

| Нужно | Почему |
|-------|--------|
| Chrome или Edge на **Android** | Web Bluetooth |
| HTTPS (prod PWA) | требование браузера |
| Датчик Heart Rate GATT | Cospo HW807, Polar и аналоги |

**Не работает на iPhone / iPad** (и в Safari): Apple не даёт Web Bluetooth. Кнопка пульса нажимается и объясняет это; подключать датчик — на Android-планшете клуба.
