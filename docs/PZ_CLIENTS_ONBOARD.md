# Клиенты ПЗ — как завести в Ось (по шагам)

**Статус:** ✅ lite-ПЗ + связка из вечерних оплат (MVP).  
Массового Excel «Часы персональных» ещё нет. Авто без выбора тренера — нельзя (в оплатах нет колонки тренера): менеджер выбирает тренера в блоке «Карточки из оплат».

**Не путать с ТЗ/АЗ:** закрытия из 1С → вкладки ТЗ/АЗ **без** живого тренера (`desk_hall`). ПЗ = клиент **с** `trainer_id`.

---

## Кому это

Админ / менеджер продаж заводит персональный зал в Оси: часть тренеров пока без планшета — клиентов ведёт админ или менеджер лёгкой карточкой; когда планшет выдали — те же карточки становятся полным дневником.

---

## Шаг 0. Подготовка (один раз на клуб)

1. **Структура → Типы абон.** — типы карт **ПЗ** (для полного дневника на планшете).
2. **Организация → Тренеры** — создать тренеров:
   - клуб, логин, пароль;
   - галка **«Без планшета»** (у нового по умолчанию включена) — админ будет заводить lite-клиентов;
   - снять галку, когда выдали планшет.
3. Кого **не** заводить как тренера: люди без клиентов ПЗ (только зал/админ).

Миграция флага: `npm run db:migrate:users-uses-tablet -- --linked` (колонка `users.uses_tablet`, у текущих = с планшетом).

---

## Вечер: оплаты → отчёт + карточки

1. **Продажи → Отчёт** — загрузить `31.xlsx`.
2. Проставить НК/ДК/УК → **Подставить** → **Сохранить** день.
3. В блоке **«Карточки из оплат»**:
   - ПЗ без карточки → тренер без планшета → **Создать** (lite);
   - ПЗ → тренер с планшетом → **Создать** (клип на планшет);
   - АЗ/ТЗ → desk (направление АЗ из тарифа).

Имя менеджера в файле пока не используем.

---

## Шаг 1. Тренер без планшета — lite-клиент (админ / менеджер)

1. **Организация** — у тренера стоит **«Без планшета»** (задаёт админ).
2. **Клиенты** (`/admin/clients` или `/sales/clients`) → **«Новый клиент ПЗ»** — ФИО, карта, телефон, тренер (только без планшета), даты/пакет абона, цена.
3. Откроется **лёгкая карточка** (контакты + абоны), как учёт desk, но **с** живым тренером.
4. В списке — бейдж **«ведёт админ»**.  
   - **В абонах / продлениях / «с действующим» / истекает** — участвуют (коммерция).  
   - **В «неактивных» и качестве ведения** — нет (пустой дневник не раздувает хвосты).  
   - **Дневной отчёт продаж** менеджера — по-прежнему руками (матрица ПЗ); lite сам туда не пишется, но карта и `paid_amount` есть для учёта и стратегии продлений.

Запись уходит в облако через очередь + flush (как архив / смена тренера).

---

## Шаг 2. Тренер с планшетом — полный ПЗ

### Уже есть планшет (продажа сегодня)

1. Менеджер: **Продажи → Заявка тренеру**.
2. Тренер: Sync → **Создать по заявке**.

### Или под логином тренера

1. Войти под логином тренера (на любом ПК/планшете клуба).
2. **Клиенты → Новый клиент** — ФИО, телефон, № карты.
3. На карточке — абонемент.
4. Sync.

---

## Шаг 3. Когда выдали планшет

1. **Организация** — снять **«Без планшета»** (`uses_tablet = true`).
2. Установить PWA на планшете → войти → **Sync**.
3. Те же клиенты с его `trainer_id` открываются как **полный дневник** (условие lite ложно). Отдельный «апгрейд» строк клиентов не нужен.

Историю занятий **до** планшета Ось не подтянет сама — она начинается с записей в приложении.

---

## Шаг 4. Если ошиблись с тренером

Админ: **Клиенты** → меню у строки → сменить тренера. Лучше переносить на тренера с тем же режимом планшета.

Уволился: **Организация** → заблокировать → клиентов переназначить.

---

## Чего не делать

| Не так | Почему |
|--------|--------|
| Грузить ПЗ через «Список заканчивающихся» (ТЗ/АЗ) | Там desk без тренера |
| Вешать ПЗ на «Не назначен» | Портит KPI / путаница |
| Создавать тренеров «на всякий» без клиентов | Лишний шум в списках |
| Ждать Excel оплат без выбора тренера | Фаза 2; в `31.xlsx` нет тренера |

## Короткий чеклист

- [ ] После выдачи планшета — галка снята, Sync на устройстве  
- [ ] Desk ТЗ/АЗ по-прежнему отдельно (без тренера)
