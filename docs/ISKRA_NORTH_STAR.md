# ИСКРА — North Star (максимум для бизнеса и «вау»)

**Версия:** 2026-07  
**Статус:** целевая картина — ориентир для спринтов, не обещание одного релиза.

---

## Одна фраза

**ИСКРА — JARVIS куратора и админа:** умный ассистент с **экономикой клуба в центре** (план, маржа, прогноз, риски) и контекстом сети/практики; учится владельцу из диалога; честно говорит, чего не хватает продукту. Для остальных ролей — облегчённая ИСКРА только в рамках клуба.

Админская ИСКРА **не урезается** — она должна стать **самой сильной на проекте**: цифры как в Статистике / Продажах / Качестве ведения, плюс действия (Планёрка). Упрощение UI — про ясный вход (бриф → экономика → сделать), не про отключение Spark.

*(Ранее: «управленческий союзник» — остаётся одним из режимов JARVIS, не потолком.)*

---

## Для кого и зачем

| Аудитория | Максимум пользы | Личный «вау» |
|-----------|-----------------|--------------|
| **Собственник / куратор** | Маржа, план, риски, прогноз, «что если» | Утренний бриф за 30 сек — как Bloomberg для зала |
| **Управляющий** | План дня, тренеры, отчёты, неактивные | Голос + док — руки свободны на объекте |
| **Админ продукта** | Техподдержка, sync, структура клуба | ИСКРА знает FIT-CITY лучше FAQ |
| **Тренер** (фаза 2+) | Свой контур: клиенты, нагрузка, челленджи | Микро-советник в кармане, не пугающий цифрами |

**North Star метрики (измеряемые):**

1. **Time-to-insight** — от открытия до понимания «что не так» &lt; 15 сек (проактивный бриф).
2. **Action rate** — ≥40% сессий заканчиваются кликом «Сделать» / чипом действия, не просто чтением.
3. **Trust score** — ≥70% оценённых ответов с 👍 (самообучение).
4. **Plan early warning** — ИСКРА подсвечивает отставание по плану **≥7 дней** раньше, чем владелец заметил сам.
5. **Retention delight** — админ открывает ИСКРУ ≥3 раза в неделю без напоминания (привычка, не пожар).

## Визуал уровня «вау»

Не «ещё один чат». **Персонаж + дата-арт + motion.**

### Принципы

1. **Орб ИСКРЫ** — фирменный объект: пульс при думании, кольца при слушании, вспышка при инсайте.
2. **Живые цифры** — KPI не таблица: дуга плана, sparkline месяца, цветовая температура (холодно/тепло/огонь).
3. **Карточки действий** — не простыня текста: заголовок, сумма в ₽, 1–2 шага, кнопка «Сделать».
4. **Сцены, не экраны** — компактный док → разворот «бриф» → полная сцена аналитики (один персонаж, три режима).
5. **Звук и голос** — TTS уже есть; **голос = тот же канал обучения**, что и текст («короче», «запомни…»). ✅ Тихий звук insight (`iskraInsightChime.js`) — mute по умолчанию; включается кнопкой громкости вместе с автоозвучкой. Вау дальше: паузы, ударения.
6. **Тёмная премиальность** — глубокий фон, акцент искры (золото/янтарь на тёмном), glassmorphism без «детского» glow.
7. **Микро-победы** — анимация при «план в темпе», subtle confetti при закрытии риска (не казино).

## Личное использование (ваш сценарий)

Как разработчик/владелец продукта:

| Сценарий | Реализация |
|----------|------------|
| Утренний кофе | SparkBrief: 3 строки + план + главный риск |

| «Что сломалось?» | ИСКРА + диагностика sync в одном потоке (app_admin) |
| Демо инвестору | Режим «презентация» — крупные цифры, без технического шума |
| Обучение нового управляющего | Playbooks + app_guide чипы |

## Технические границы (не ломаем)

- **Vercel ≤12 functions** — всё через `admin-data?action=`
- **Офлайн-first** — бриф и KPI из кэша; Gemini только online
- **Тонкий UI, толстая lib** — визуал в компонентах, логика в `iskra*.js` + verify
- **Один snapshot** — `clubMonthAnalyticsCore`, без дублирования agg

## Definition of Done для North Star

Считаем цель достигнутой, когда одновременно:

1. Владелец открывает **SparkBrief** и за **15 сек** понимает месяц.
2. **InsightCard** предлагает действие с **оценкой в ₽** и кнопкой «Сделать».
3. ИСКРА **помнит** playbooks клуба и прошлый месяц.
4. Визуал: орб, дуга плана, карточки — **узнаваемый бренд FIT-CITY**.
5. 👍 rate ≥70% на оценённых ответах за 30 дней.
6. Управляющий работает **без админских** финансовых деталей, но с полным операционным контуром.
