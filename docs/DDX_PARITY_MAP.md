## Турникет (п.10) — коротко

**Ситуация:** клиент у входа показывает QR → турникет пускает (как в DDX).

**Что делает Ядро:** «этому человеку сегодня можно в этот клуб?» (абонемент, заморозка, клуб).

**Что не делаем сами:** железо турникета, монтаж, контроллер вендора — **адаптер** к партнёру СКУД.

**Порядок кусков (когда дойдём):**  
1) стабильная правда абонемента → 2) идентификатор пропуска (QR/токен) → 3) API «пустить/нет» → 4) интеграция с контроллером → 5) журнал проходов в карточке/клубе.
