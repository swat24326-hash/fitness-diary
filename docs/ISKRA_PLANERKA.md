# Планёрка — задания команде из FIT-CITY

**Рабочее название** (2026-07). Раньше в планах называлось «Пульс команды».  
**Статус:** v1 MVP реализован — см. [ISKRA_DISPATCH.md](./ISKRA_DISPATCH.md).

---

## Что такое Планёрка (простыми словами)

**ИСКРА** подсказывает: «вот что не так в цифрах».  
**Планёрка** — это когда вы **ставите конкретное задание** сотруднику в приложении: кому, что сделать, до какого срока.

Как короткая планёрка у доски — только в цифровом виде, без Telegram.

| Шаг | Кто | Что происходит |
|-----|-----|----------------|
| 1 | Админ / руководитель | Видит карточку ИСКРЫ или создаёт задание вручную |
| 2 | | Жмёт **«Назначить»** → выбирает тренера (или менеджера) |
| 3 | Тренер | В шапке планшета — **Планёрка** (бейдж с числом новых) |
| 4 | Тренер | Открывает список → **Принял** → делает → **Выполнено** |

**Не чат.** Одно задание, один ответ, статус «сделано / не могу».

---

## Идея в одной фразе

**ИСКРА видит проблему — Планёрка доводит задачу до рук сотрудника** в FIT-CITY: один получатель, срок, контекст из цифр.

---

## Зачем клубу

| Боль сейчас | Планёрка |
|-------------|----------|
| «Увидел в ИСКРЕ — написал в Telegram» | Задание из карточки в 2 клика |
| Тренер не знает приоритет | Заголовок + ₽ + срок |
| Нет следа «кто что обещал» | Статус: новое → принято → сделано |
| Повтор одних напоминаний | Playbooks + авто-задания (v2) |

---

## Что это НЕ

- Не WhatsApp / Telegram внутри приложения.
- Не пульс сердца в тренировке (другое слово, другой экран).
- Не замена sync — задание **ведёт** на экран клиента / отчёта.
- Не отдельный Vercel function — `admin-data?action=iskra-dispatch`.

---

## Модель: задание, не переписка

```
Инсайт ИСКРЫ → Задание → Получатель → Действие в приложении → Закрытие
```

### Типы заданий (v1)

| `task_kind` | Пример |
|-------------|--------|
| `reactivate_clients` | Связаться с неактивными |
| `daily_report` | Внести отчёт за день |
| `plan_push` | Дожать план / ПЗ |
| `training_hygiene` | Закрыть тренировки без типа |
| `custom` | Свой текст |

### Статусы

`pending` → `seen` → `accepted` → `done` | `declined` | `dismissed`

## Кто кому

| Отправитель | Получатели |
|-------------|------------|
| **Админ** | тренеры, менеджер, управляющий |
| **Управляющий** (позже) | тренеры, менеджер своего клуба |
| **ИСКРА** (v2) | по триггеру, с подтверждением |
| **Тренер** | только **получает** |

## UX-сценарии

### Из карточки ИСКРЫ (сейчас)

1. Карточка «Много неактивных» + ₽
2. **Сделать** — вопрос в чат ИСКРЫ | **Назначить** — в Планёрку
3. Выбор тренера, срок, **Отправить**
4. Тренер видит в **Планёрке** в шапке

### Ручное задание (план O1)

Отдельный экран «Задания клуба» — без открытия ИСКРЫ. См. [CLUB_OPERATIONS_PLAN.md](./CLUB_OPERATIONS_PLAN.md).
