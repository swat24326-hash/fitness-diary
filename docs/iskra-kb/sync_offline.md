# Sync и офлайн на планшете

1. Кнопка Sync в шапке приложения (иконка обновления).
2. Порядок: сначала отправка очереди на сервер (ваши локальные записи), потом подтягивание из облака.
3. На планшете без сети — работайте как обычно; записи в IndexedDB и очереди.
4. Когда сеть появилась — Sync; не обновляйте страницу принудительно до завершения.
5. Если «висит» pending — откройте Диагностику (админ) или повторите Sync.

> Pull не затирает записи, которые ещё не отправлены. Критично для стабильности на планшете тренера.
