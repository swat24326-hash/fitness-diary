# Воронка ПНК (потенциальный новый клиент)

1. Менеджер: `/sales` или `/sales/pnk` → создать ПНК (1 или 2 бесплатные) → назначить тренера → передать.
2. Тренер открывает карточку клиента — липкая шапка воронки: прогресс и «Назад / Далее / Пропустить».
3. Шаги по сценарию: контакт и дата → старт визита → здоровье → питание → тренировка → ДЗ → (вторая тренировка при двух БЗ) → контакт после → оформление ДК или отказ.
4. Абонемент **БЗ** с флагом пробного ПНК должен быть в типах карт клуба.
5. KPI «оформления / ПНК» — на доске менеджера и в статистике; качество визита (сделано / слабо / нет) — у админа.

> Та же карточка клиента, не отдельное приложение. Подробный сценарий проверки: docs/PNK_FUNNEL.md.
