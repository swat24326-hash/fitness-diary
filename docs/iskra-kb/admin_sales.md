# Отчёты менеджера (продажи)

1. Админка → «Продажи» (отчёт менеджера за день). Менеджер по продажам входит в `/sales`.
2. Заполняйте ежедневно: выручка НК/ДК/УК, матрица ПЗ/ТЗ/АЗ, ПНК, возвраты.
3. Эти цифры — источник для ИСКРЫ в сегменте «Продажи»: план, прогноз, направления. Прогноз на конец месяца учитывает разные средние будней и выходных (если хватает отчётов обоих типов).
4. ИСКРА не подменяет отчёт — анализирует то, что внесено.
5. Воронка ПНК (создание и доска) — отдельно: «ПНК» / `/sales/pnk`.

> Планшеты тренеров — другой контур; для плана продаж используйте только отчёты менеджера.
