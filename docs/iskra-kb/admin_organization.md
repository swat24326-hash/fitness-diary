# Организация: клубы и тренеры

1. Админка → «Организация».
2. Клубы: список филиалов, выбор активного клуба в шапке админки.
3. Тренеры: создание учётной записи тренера, привязка к клубу.
4. После создания тренер входит на планшет под своим логином — видит своих клиентов.
5. Справочники (упражнения, типы карт) — отдельные разделы админки.

> ИСКРА и статистика клуба работают по клубу, выбранному в шапке.
