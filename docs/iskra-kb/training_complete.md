# Как провести и завершить тренировку (планшет)

1. Тренер → главная или «Клиенты» → выберите клиента.
2. «Новая тренировка» — создаётся черновик на сегодня (кнопка доступна и если абон ещё «ждёт старт»).
3. Если абонемент ещё «ждёт старт», а клиент пришёл раньше — подтвердите сдвиг дат на экране, затем откроется форма.
4. Добавьте упражнения, подходы, веса — данные пишутся локально.
5. По окончании нажмите «Завершить» — статус completed.
6. При завершении списывается тренировка с абонемента (если тип карты это предусматривает).
7. Нажмите Sync в шапке, когда есть сеть — тренировка уйдёт в облако.

> Офлайн можно завершать тренировку — она встанет в очередь sync. Без типа карты тренировка не попадёт в личную ЗП тренера в ИСКРЕ.
