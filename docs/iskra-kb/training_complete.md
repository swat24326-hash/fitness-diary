# Как провести и завершить тренировку (планшет)

1. Тренер → главная или «Клиенты» → выберите клиента.
2. «Новая тренировка» — создаётся черновик на сегодня.
3. Добавьте упражнения, подходы, веса — данные пишутся локально.
4. По окончании нажмите «Завершить» — статус completed.
5. При завершении списывается тренировка с абонемента (если тип карты это предусматривает).
6. Нажмите Sync в шапке, когда есть сеть — тренировка уйдёт в облако.

> Офлайн можно завершать тренировку — она встанет в очередь sync. Без типа карты тренировка не попадёт в личную ЗП тренера в ИСКРЕ.
