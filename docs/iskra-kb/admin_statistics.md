# Статистика клуба

1. Админка → «Статистика» при выбранном клубе в шапке.
2. Вкладки **ПЗ | ТЗ | АЗ** — типы карт и зал; не складывать три вкладки в «число людей».
3. **Всего / действующие / не активные** — в «Клиентах» (фильтры воронки), не на статистике (и у тренера тоже).
4. На **ПЗ** ещё: ПНК→ДК, тренировки, рейтинг, качество ведения, год. На ТЗ/АЗ этих карточек нет.
5. На **ТЗ/АЗ** «По типам» — число абонов зала по типу карты.
6. Детализация по тренерам и типам карт — для операционного контроля.
7. Для управленческих советов и плана — ИСКРА (сегмент «Продажи»).
