# Статистика клуба

1. Админка → «Статистика» при выбранном клубе в шапке.
2. Вкладки **ПЗ | ТЗ | АЗ** — цифры клиентов и типы карт по залу; не складывать три вкладки в «число людей».
3. На **ПЗ** в «Всего» только абон ПЗ (или legacy без абонов); человек только с ТЗ/АЗ туда не попадает.
4. На **ТЗ/АЗ** «По типам» — число абонов зала по типу карты, не тренировки планшета.
5. На **ПЗ** ещё: ПНК→ДК, тренировки, рейтинг, качество ведения, год. На ТЗ/АЗ этих карточек нет (desk без планшетных тренировок).
6. Детализация по тренерам и типам карт — для операционного контроля.
7. Для управленческих советов и плана — ИСКРА (сегмент «Продажи»).
