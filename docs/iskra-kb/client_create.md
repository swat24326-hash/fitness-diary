# Как создать клиента

1. Админка → раздел «Клиенты».
2. Кнопка «Добавить» (или «+»).
3. Укажите ФИО, при необходимости телефон и e-mail.
4. Выберите тренера из списка — клиент привязывается к тренеру.
5. Сохраните — откроется карточка клиента.
6. Дальше: абонемент, медкарта, первая тренировка — из карточки.

> Без тренера клиент не попадёт в список планшета. Для клуба с несколькими тренерами проверьте правильного исполнителя.
