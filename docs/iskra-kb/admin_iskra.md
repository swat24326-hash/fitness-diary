# ИСКРА: как пользоваться

1. Иконка ИСКРЫ в админке → панель с двумя сегментами: «Продажи» и «Тренеры».
2. «Продажи» — план, выручка, НК/ДК/УК, ПЗ/ТЗ/АЗ из отчётов менеджера. Чип «Совет по плану» — развёрнутый совет Gemini.
3. «Тренеры» — планшеты: тренировки, личная ЗП, неактивные клиенты. Не смешивается с продажами.
4. Режим «Стандарт» / «Подробно» — глубина ответа в чате. Уроки клуба — в «Настройки ИСКРА».
