# Как оформить абонемент

1. Откройте карточку клиента → вкладка «Абонементы».
2. «Добавить абонемент» → выберите тип из справочника (НК/ДК/УК и формат ПЗ/ТЗ/АЗ).
3. Укажите дату начала, срок, количество тренировок или безлимит — по типу карты.
4. Сохраните. Действующий абонемент виден в карточке и на планшете тренера.
5. Списание тренировки — при «Завершить» тренировку на планшете (дата тренировки важна для абонемента).

> Типы карт настраиваются в админке: «Типы абонементов». Ставки для ЗП тренера тоже там.
