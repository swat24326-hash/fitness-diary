# FIT-CITY: общая схема

1. Два контура: планшет тренера (клиенты, тренировки, офлайн) и админка (клуб, продажи, статистика, ИСКРА).
2. Данные: локально на устройстве + облако Supabase после Sync.
3. Тренер: клиенты → тренировка → завершить → sync.
4. Админ: клиенты и абонементы, организация, ежедневные отчёты продаж, ИСКРА для решений.
