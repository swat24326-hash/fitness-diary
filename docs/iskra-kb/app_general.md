# FIT-CITY: общая схема

1. Два контура: планшет тренера (клиенты, тренировки, офлайн) и админка (клуб, продажи, статистика, ИСКРА). Менеджер продаж — отдельный вход `/sales`.
2. Данные: локально на устройстве + облако Supabase после Sync.
3. Тренер: клиенты → тренировка → завершить → sync. ПНК — мастер на той же карточке клиента.
4. Админ: клиенты и абонементы, организация, ежедневные отчёты продаж, ИСКРА для решений.
