- **Главная / Продажи:** виджет плана не тянет bundle на каждый заход — session-кэш ~2 ч; сброс после сохранения отчёта/плана.
- **Статистика / качество ведения:** лёгкая сводка и CQ параллельно (`include_cq=0` + `action=coach-quality`); сводка дня без двойного тяжёлого запроса.
- **Статистика (тренер/клуб):** сначала лёгкие карточки периода, «Качество ведения» догружается вторым шагом («считаем…»).
- **Продажи / план по сегментам:** «В темпе» — по сумме и прогнозу; отставание штук или среднего чека — чипы «штуки» / «чек», без общего «Отстаём».
- **Главная / Продажи:** под шкалой плана — мелкие цифры факт и прогноз: чистая прибыль, тренировки ПЗ и АЗ.
- **Клиенты:** без действующего абонемента — разные подписи и точка: «начнётся ДД.ММ» (светлый круг), «закончился…», «лимит исчерпан», «нет абонемента» (красный квадрат); не одно «нет активного».
- **Тренер / Качество ведения:** после сводки с сервера балл догружается с планшета (API специально не считает CQ).
- **Тренер / ЗП:** запрос типов карт без колонки `name` (её нет на проде) — иначе fallback на кэш.
- **Тренер / планшет:** ЗП+статистика — один общий запрос к серверу (не два); при сбое видна причина; лёгкий select без тяжёлого JSON тренировок.
- **Тренер / профиль:** ЗП и статистика считаются на **сервере** (`trainer-self-stats`); при сбое сети — последние успешные цифры, не пустые нули.
- **Тренер / ЗП:** на слабом Wi‑Fi планшета — дольше ждём облако, частичный ответ и автоповтор (не сырой `timeout`).
- **Тренер / ЗП:** «Моя зарплата» при сети считает из облака (не только локальный кэш) — цифры на планшетах сходятся.
- **Тренировка / сплит:** при переключении черновиков снова открывается тот же шаг формы (не сбрасывается на «Опрос»).
- **Клиенты / абонементы:** меню «⋮» больше не прячется под кнопки и скролл таблицы — панель поверх экрана.
- **Тренировка:** пульс BLE в общей шапке (до 2 клиентов); цвет по зоне; «Снова» при обрыве; сводка/зоны/ккал на «Итоге»; буфер переживает reconnect/reload. [docs/TRAINING_HR.md](./docs/TRAINING_HR.md).
- **Клиенты:** плитка **ПНК** в сводке + бейдж «ПНК» в списке (как у тренера); «Все клиенты» без воронки.
- **Sync / абонементы:** обновление без даты начала больше не ломает очередь (пустые даты не пишутся в облако как null); в карточке абонемента дату нельзя сохранить пустой.
- **Клиенты:** исчерпанный абонемент + купленный вперёд → только «Ждёт старт», не «Не активные».
- **Sync:** создание и сразу удаление абонемента не воскрешает запись в облаке (схлопывание insert/delete перед push).
- **Sync:** ранняя активация офлайн не откатывается — update схлопывается в pending insert; битый insert без дат снимается с очереди.
- **Абонементы:** нельзя сохранить период, где окончание раньше начала.
- **SMS клуба:** предупреждение, если облачный журнал не записался; явная ошибка, если нет таблицы `club_sms_log`.
- **Тренер:** если абонемент «ждёт старт», а клиент пришёл раньше — подтверждение сдвига дат и сразу старт тренировки.
- **Клиенты / SMS:** облачный журнал `club_sms_log` — общие отметки на устройствах клуба; блок «Журнал SMS» в Структура → Max и SMS.
- **Клиенты / SMS:** отметка «уже писали» — **Истекает** до 3 дн., **Закончился** и **Давно не был** до 14; в «Все» видна, пока клиент в той же корзине.
- **Клиенты:** плитка **«Ждёт старт»** — куплен абонемент со стартом впереди (не цель для SMS «вернись»).
- **Главная админа:** сводка дня и мягкие сигналы — цифры воронки (закончился / давно не был / ДР / ждёт старт) со ссылками в Клиенты.
- **Клиенты / SMS:** после отправки — отметка у кнопки SMS на этом устройстве (локальный журнал; срок зависит от корзины).
- **Клиенты / тренер:** «ждёт старт» (куплен абонемент вперёд) не в неактивных и не в «Закончился / Давно не был» — общая логика с тренерской воронкой.
- **Клиенты:** сводка как у тренера — Все · Не активные · Ждёт старт · ДР · Истекает · Закончился · Давно не был.
- **Клиенты:** сводка на сегодня — крупные плитки на ширину экрана: цифра + подпись сразу; «?» — подробная подсказка.
- **Клиенты / SMS:** отдельные шаблоны «от клуба»; на фильтрах ДР / Истекает / Закончился / Давно не был — шаблон сценария, иначе свой текст. [docs/MOIZVONKI_SETUP.md](./docs/MOIZVONKI_SETUP.md).

- **ИСКРА:** фирменный янтарный орб (idle / слушает / думает / инсайт) в шапке, доке, панели и брифе; строки брифа по очереди; тихий звук insight — mute по умолчанию, включается кнопкой громкости вместе с автоозвучкой.

- **Итог визита ПНК:** «Здоровье» и «Обмеры» — один пункт в зале; на вкладке карта и замеры уже вместе. Воронка и шаг `health` без ломки.
