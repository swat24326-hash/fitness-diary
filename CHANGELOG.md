## 2026-07

- **Клиенты / SMS:** отдельные шаблоны «от клуба» (не тексты Max тренера); настройка — Структура → Max и SMS. Перед отправкой — лист подтверждения; шаблон «продлим» только на фильтре «Истекает ≤ 3 дня», на «всех» — свой текст. [docs/MOIZVONKI_SETUP.md](./docs/MOIZVONKI_SETUP.md).
- **Клиенты:** сводка на сегодня — компактные квадраты под цифру; название фильтра — по «?».
- **Главная админа:** «Не активные» открывает список в **Клиентах** (лёгкий фильтр), а не всю Статистику.
- **ИСКРА:** фирменный янтарный орб (idle / слушает / думает / инсайт) в шапке, доке, панели и брифе; строки брифа по очереди; тихий звук insight — mute по умолчанию, включается кнопкой громкости вместе с автоозвучкой.
- **Админка / клиенты:** кнопка SMS через «Мои Звонки»; шаблоны клуба отдельно от Max — [docs/MOIZVONKI_SETUP.md](./docs/MOIZVONKI_SETUP.md).
- **Итог визита ПНК:** пока клиент не в зале, «Начало тренировки» — «ждём», не «нет» (связь и дата уже ок — не штрафуем).
- **Продажи / статистика:** клик по числу в «Тренировки в аэробном зале» — окно с расшифровкой по дням (как тренировки абонемента); тап по дню открывает отчёт.
- **Продажи / отчёт за день:** тап по дате с календарём открывает полный выбор дня (не только стрелки ◀ ▶).
- **Доска ПНК:** плитки снова квадратные в ряд (несколько БЗ на одной линии), без сжатия дат и имён.
- **Итог визита ПНК:** сводка только по статусам с числом > 0; «слабо» → «частично»; подсказки на чипах.
- **Итог визита ПНК:** «Здоровье» и «Обмеры» — один пункт в зале; на вкладке карта и замеры уже вместе. Воронка и шаг `health` без ломки.
- **ПНК:** кнопки шапки и Max / мессенджер / карточка / удалить — только иконки; убрана боковая колонка Max на шаге «Ждём в зале».
- **Итог визита ПНК:** фазы «До визита / В зале / После» в три колонки — панель ниже по высоте.
- **Итог визита ПНК:** компактнее; пока клиент не в зале — пункты пакета не штрафуют («ждём»); «Клиент в зале» → «Начало тренировки» с датой бесплатной.
- **Доска ПНК:** панель «Итог визита» читаемее — чипы сделано/слабо/нет, фазы блоками, маркеры статуса, полоска полноты.
- **Доска ПНК:** убраны подпись «Сводка месяца» и пояснение для админа — экран чище.
- **Главная тренера:** плотная доска под планшет — компактный «Дневник», задания и ПНК рядом, «Сегодня внимание» в один ряд на всю ширину; с ПНК всё помещается без зума 50%.
- **Главная тренера:** «Качество ведения» больше не зависает на «Загрузка…» после обновления / повторного Sync.
- **Главная тренера:** пять карточек «Сегодня внимание» в один ряд (ПНК уже остальных); виджет ПНК узкий, не на всю ширину.
- **Виджет ПНК:** имя и этап слева, статус справа — два столбца, карточка уже.
- **ПНК:** этапы понятнее — «Создан ПНК» → связь → дата → ждём в зале → пункты визита → касание → оформление; «Итог визита» сгруппирован (до визита / в зале / после).
- **ПНК (админ/продажи):** доска 50/50; слева квадратные плитки в ряд; в «Итоге визита» видна дата/время назначенной бесплатной.
- **Главная админа:** карточка «Качество ведения» — средний балл, шкала с отметками 70/85, бейдж статуса и факты брифа (на разбор / внимание / просели), без пустого поля.
- **Планшет тренера:** главная и карточка ПНК заполняют ширину экрана (не узкая колонка 920px); на широком планшете виджеты в две колонки; шаги «приглашение / старт визита» — шапка воронки слева, Max справа.
- **Главная админа:** убран чип «отчёт продаж» (это зона менеджера в Продажах); в пустой слот ряда — «Качество ведения» с баллом /100.
- **Главная админа / менеджера:** сводка дня — 2 сигнала + «Ещё»; пустые слоты ряда заполняют мягкие сигналы (качество, неактивные…); плитки ПНК/планёрка приглушены, если виджет уже сверху.
- **Главная менеджера продаж:** тот же ряд план + ПНК + планёрка, что у админа.
- **Главная админки:** план продаж, ПНК и планёрка — в одном ряду: без боковых виджетов план на всю ширину; с ПНК/заданиями план короче, справа горячее.
- **Главная админа / продажи:** виджет ПНК — шапка с шагом справа, статус на всю ширину, шкала отдельно (не куча в углу).
- **Главная админа:** «Диагностика» и настройки «ИСКРА» — во вкладках **Структура**; на главной семь разделов в один ряд (ПНК … Планёрка).
- **PWA после деплоя:** если в журнале «Failed to fetch … PwaUpdatePrompt-….js» — это старая вкладка после обновления сайта, не Sync. Жмите Ctrl+F5 (или закройте и откройте приложение); дальше страница сама перезагрузится один раз.
- **ИСКРА / экономика:** бриф и KPI показывают план и **норму к дате** как в Продажах; тон дуги — отставание от нормы, не «магические 45%».
- **Настройки ИСКРА:** на виду бриф и быстрые кнопки; уроки клуба и дополнение промпта — свёрнуты (редко); убран справочный список «что нужно управленцу».
- **ИСКРА / голос:** снова **Microsoft Online Natural** (Edge + VPN) первым; иначе Desktop; иначе neural Svetlana; Google только в самом конце.
- **Планёрка / push:** менеджер продаж снова может включить уведомления (раньше API отдавал 403 на ключ VAPID, в UI казалось «не настроен»). [docs/PUSH_SETUP.md](./docs/PUSH_SETUP.md).
- **ИСКРА (админ):** JARVIS + обучение из диалога/Планёрки/неделания; исходы советов; бриф для собственника; голос = тот же канал памяти; «вы vs прошлый вы»; честный потолок надёжности %; контекст «Качество ведения». [docs/ISKRA_NORTH_STAR.md](./docs/ISKRA_NORTH_STAR.md).
- **Продажи / план и прогноз:** KPI без дублей; норма в ₽; отставание залов только в таблице; факт-итоги не повторяют таблицу прогноза.
- **Список клиентов:** карточка читается по ширине (имя · факты · действия); «Карточка» у админа — иконка; архив/удаление в «⋮».
- **Sync:** вместо техсписка «части…» — короткие фразы под шапкой; % на кнопке; подробности в Помощи → «Последний Sync».
- **Главная админа:** при обновлении — спокойные скелетоны вместо трёх спиннеров «Загрузка…».
- **Админ → Клиенты:** «Последняя тренировка» подтягивается из облака, если на этом устройстве нет дневника в кэше; «осталось» не обнуляется из‑за пустого кэша.
- **Дизайн (волна D):** единые empty/loading, крупные тапы списка клиентов, форма тренировки спокойнее, планёрка с бейджем «Просрочено», glass у диагностики/челленджей, лёгкое появление карточек.
- **Главная админа:** в сводке дня — виджет «Качество ведения» (балл /100, на разбор · просели) → статистика.
- **Статистика клуба (MVP):** один заголовок; «Не активные» с главной → список в статистике; мёртвые карточки помечены; «Итог» = календарный год; deep-link качества ведения.
- **Главная админа:** виджет факт/план продаж месяца (как в продажах), в стиле champagne-оболочки.
- **Админ / продажи:** accent по роли (champagne / cyan), без «зелёных» утечек на плитках и отчёте; ПНК-чипы на токенах. [docs/BRAND_SYSTEM.md](./docs/BRAND_SYSTEM.md).
- **Путь тренера:** единая шапка на клиентах / карточке / тренировке; статусы и Max — через токены роли. [docs/BRAND_SYSTEM.md](./docs/BRAND_SYSTEM.md).
- **Главная тренера:** снова Font Awesome-гантель (как раньше); чтение настроек «Качества ведения» без 403 в консоли.
- **Бренд:** продукт — **Ось**; логотип — шевроны + ОСЬ. В шапке крупно **клуб**, Ось — тихий знак. [docs/BRAND_SYSTEM.md](./docs/BRAND_SYSTEM.md).

- **Документация:** зафиксирована крупная цель продукта — ОС клуба (зал, продажи, управление, учёт; сайт заявок и касса позже; ИСКРА сверху). [docs/PRODUCT_VISION.md](./docs/PRODUCT_VISION.md).

- **Качество ведения:** в Структуре — настройка весов осей и тумблеров правил (одинаково для админа и тренера). [docs/COACH_QUALITY.md](./docs/COACH_QUALITY.md).
- **Качество ведения:** пустая карта здоровья и отсутствие рациона при работе с весом снижают балл; данные карт подгружаются на сервере. [docs/COACH_QUALITY.md](./docs/COACH_QUALITY.md).
- **Качество ведения:** карточка в сетке статистики (средний балл) → по клику ровная таблица по тренерам. [docs/COACH_QUALITY.md](./docs/COACH_QUALITY.md).
- **Качество ведения:** оценка в статистике клуба считается на сервере вместе со сводкой (не «0 тренировок» из‑за пустого кэша админа). [docs/COACH_QUALITY.md](./docs/COACH_QUALITY.md).
- **Качество ведения:** в статистике клуба и у тренера — ведение, глубина дневника, хвосты в «Неактивных» (ДК и после БЗ); видно направление просадки. [docs/COACH_QUALITY.md](./docs/COACH_QUALITY.md).
